# 联网搜索

按问题选择合适的能力：

| 能力 | 适用场景 |
|---|---|
| `web_search` | 网页查找、近期信息和事实核验；由当前模型 Provider 提供，费用和可用性按 Provider 配置 |
| `deep_research` | 多来源研究、总结、比较和引用；使用管理员配置的研究 Provider，可能有每日额度 |
| `similar_image_search` | 用已有图片找相似候选，不用于文字关键词搜图 |
| `http_get` | 阅读已找到的单个网页 |
| `read_file` | 查看本地文件或选中的图片候选 |

## 选择路径

1. 一般网页查询使用 `web_search`。先提炼实体、版本、日期和关键词；参数按当前 Provider 返回的 Schema 填写。
2. 需要跨来源汇总、行业研究或多方案比较时，组合 `web_search`、`http_get` 和 `deep_research`。不必每次调用全部能力；关键事实应核对独立来源。
3. 已有图片要找同款、角色或出处时，先加载 `image-analysis`，调用 `similar_image_search`。候选只代表相似，不代表身份已确认。
4. 仅有文字、要求搜索网络图片时，目前没有关键词图片搜索能力；如有必要，说明限制或请用户提供图片线索。
5. 只读一篇页面时使用 `http_get`；研究结论应附真实来源链接，不猜 URL。

## 真实性与安全

- 推荐、列举或比较具体对象时，核验名称、作者、型号、版本和出处；不确定就收窄结论或说明不确定。
- 新闻、赛事、价格、版本和人物任职等时效信息，确认来源时间、事件时间和当前状态；重大事实优先核对官方来源或多个独立来源。
- Provider 的生成式答案是线索，不是事实证明。来源冲突时说明差异，不隐藏反例。
- 用户请求宽泛新闻而没有主题、对象或地区时，先问一个最小限定；明确范围后收敛搜索，不反复追问。
- 涉及敏感公共事件时，只保留必要的中性事实、来源和日期，不复述或渲染细节。Provider 拒绝后不要通过改写同一内容绕过限制。
- 不把“本次未查到”说成“不存在”；工具失败不代表网上没有相关信息。
- 最终答复中的链接必须来自实际搜索或读取结果。只有标题没有链接时，不要猜测地址。
