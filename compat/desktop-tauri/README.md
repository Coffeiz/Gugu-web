# 旧 Tauri 桌面验证源码归档

此处保留 Electron 切换前的 Rust Host、Tauri 配置、固定 MXC 验证及图标来源，供追溯和实现对照；源码未删除。

当前活动桌面入口、依赖、打包和 CI 均位于 `gugu-desktop/`，不再装配此目录。旧配置中的相对路径、Tauri bridge 及 Python/Node 制品假设属于历史实现，不能直接套用到当前 Vue/Electron 入口。

当前职责及完成状态见 [架构与迁移任务清单](../../docs/refactor/Gugu-2.0-架构与迁移任务清单.md)。本目录不随新功能维护，也不作为发行制品或 CI 通过的证据。
