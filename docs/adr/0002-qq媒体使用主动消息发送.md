# ADR-0002：QQ 文件与图片使用主动消息发送

> 状态：已接受
> 创建：2026-10-18
> 最近更新：2026-10-18
> 关联范围：QQ 私聊与群聊中的文件附件、图片和 Mermaid 图表
> 关联文档：无

## 0. 决策摘要

| 决策主题 | 当前结论 | 主要边界 |
|---|---|---|
| QQ 文件与图片 | 以主动消息发送，不关联触发本轮任务的 `msg_id` | 仍受 QQ 主动消息频控及用户接收设置影响 |
| QQ 文本回复 | 继续使用被动回复，并遵守入站消息的回复次数和有效期 | 被动额度耗尽时沿既有主动回退路径处理 |

## 1. 背景与问题

QQ 被动回复有按入站消息计算的次数和有效期限制。长任务中可能先发送进度或正文，再输出 Mermaid 图像或多个文件，导致媒体发送与正文共同消耗同一条入站消息的被动回复额度。额度耗尽或窗口过期会让附件发送失败。

QQ 主动消息使用独立的频率和每日额度。用户也可以在 QQ 客户端关闭接收主动消息；关闭后主动发送会失败。产品接受在这一平台规则下发送媒体，而不把媒体额度混入被动回复计数。

当前依据为 QQ 官方[主动消息与被动消息说明](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html#%E4%B8%BB%E5%8A%A8%E6%B6%88%E6%81%AF%E4%B8%8E%E8%A2%AB%E5%8A%A8%E6%B6%88%E6%81%AF)。较早的文档镜像可能保留旧频控口径，不作为当前规则来源。

## 2. 目标与约束

### 2.1 目标

- 长任务产生的 QQ 文件和图片不因被动回复次数或时间窗口耗尽而失去发送机会。
- Mermaid 图像和通过统一 IM 文件发送流程传送的文件采用一致的主动发送规则。
- 保留文本回复与媒体发送各自的频控语义，并向用户报告发送失败。

### 2.2 范围外

- 不取消 QQ 的主动消息频率、每日额度或用户接收开关。
- 不把普通 QQ 文本回复全部改为主动消息。
- 不改变飞书、Telegram、微信等平台的消息策略。

## 3. 候选方案

| 方案 | 取舍 |
|---|---|
| 文件和图片继续使用被动消息 | 可关联原入站消息，但长任务或多媒体回复可能耗尽被动回复额度 |
| 文件和图片使用主动消息，文本保留被动回复 | 媒体不消耗被动额度；发送受主动消息频控和用户接收设置约束 |
| 所有回复都使用主动消息 | 统一消息类型，但会改变普通文本回复语义并额外占用主动消息额度 |

## 4. 决策

- QQ 私聊与群聊的文件附件统一不传 `msg_id`，作为主动消息发送。
- QQ Mermaid 渲染图片同样不传 `msg_id`，并且不增加被动回复计数。
- Mermaid 的纯文本内容仍遵循文本回复规则；被动额度耗尽时沿既有主动回退路径发送。
- 用户关闭主动消息或 QQ 主动消息频控拒绝发送时，发送结果必须作为失败处理；IM 文件发送流程向用户反馈失败，不得报告附件已送达。
- 网关底层保留接受 `msg_id` 的能力，以支持其他明确需要被动消息的调用方；统一 IM 媒体发送入口负责采用本 ADR 的主动发送策略。

## 5. 后果与取舍

- 媒体发送不会消耗同一入站消息的被动回复次数，长任务可以继续发送图片和文件。
- 用户禁用了主动消息、达到主动消息频控或平台权限不足时，媒体仍可能发送失败；主动发送不等于无限配额或保证送达。
- 文本回复保持现有行为，避免将整段会话无差别迁移到主动消息。

## 6. 依据与验证

- QQ 官方主动/被动消息文档区分两类消息的时效与频控，并说明用户可以设置是否接收主动消息。
- 当前实现通过 QQ 网关的文件发送接口发送附件；`msg_id` 为空时请求不关联被动回复窗口。
- 自动化回归验证 Mermaid 图片和普通 QQ 文件发送均不携带入站 `msg_id`，且不会消耗被动回复计数。
- 验证范围不包括 QQ 线上账号的主动消息开关、配额和真实投递结果；这些仍取决于 QQ 平台及机器人配置。

## 7. 重新评估条件

若 QQ 官方调整主动消息的媒体类型权限、频控或用户接收策略，或咕咕新增统一的跨平台主动发送调度能力，应重新评估本决策及各平台媒体发送策略。
