# ADR-0009：QQ 私聊最终答复流式交付与回退

> 状态：已接受
> 创建：2026-10-23
> 最近更新：2026-10-24
> 关联范围：QQ 私聊、群聊正文交付与成功状态
> 关联文档：`docs/adr/0002-qq媒体使用主动消息发送.md`、`docs/adr/0006-qq工具事件不并入流式回复.md`

## 背景

长任务存在 Web 已生成完整正文、QQ 未收到最终答复且仍显示输出中的现场。不能仅凭任务完成或曾发送过过程文字，判定最终答复已完整交付；现有现场未保留逐帧回执，不能把所有实例都归为被动消息过期。

## 决策

- QQ 私聊 Markdown 回复在生成期间通过 QQ 流式消息实时交付最终正文；正常结束时收尾当前流，不再额外发送一份重复最终正文。取消任务不补发终态正文。
- 没有可用入站 `msg_id`、流式创建不可用或普通传输失败时，将尚未确认交付的文字交给普通回复出口；该出口优先使用被动回复，并在消息 ID 过期或发送失败时按 QQ 出站策略回退主动消息。不得重发已经确认送达的流式前缀。
- 流式收尾失败不能因先前有可见前缀而被误判为最终交付成功。错误终态仍通过普通回复出口发送，避免先流式发送错误正文、随后又发送一次。
- 群聊及非流式/兼容路径继续使用普通回复出口；工具消息、图片和附件仍遵循各自既有发送策略。取消不补发最终正文。
- 已有客户端悬挂气泡不能在缺少原 `stream_msg_id` 时可靠关闭，本次不声称追溯修复旧气泡。

## 取舍

私聊最终答复恢复逐字流式展示。流式与普通回复仍受平台配额、频控、接收开关及内容审核限制，不是保证送达机制；失败不能伪装成成功，也不能无界重发。保留既有图文渲染、附件处理和受限诊断边界。

本决策替代 ADR-0002 中“所有普通正文均保持被动发送”的最终答复部分，以及 ADR-0006 中“最终正文继续使用流式”的部分；工具与媒体的独立发送规则保持有效。未修改用户运行配置或数据库结构。

## 验证

合成渠道回归覆盖：私聊最终正文通过流式消息交付且不重复发送；缺少入站消息 ID 时走普通回复；回退失败和最终收尾失败不误报成功；错误终态、取消及群聊继续走普通回复路径。测试不向真实 QQ 发送消息，不承诺真实账号的配额或端到端成功率。
