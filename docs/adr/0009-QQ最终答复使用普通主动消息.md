# ADR-0009：QQ 最终答复使用普通主动消息

> 状态：已接受
> 创建：2026-10-23
> 最近更新：2026-10-23
> 关联范围：QQ 私聊、群聊正文交付与成功状态
> 关联文档：`docs/adr/0002-qq媒体使用主动消息发送.md`、`docs/adr/0006-qq工具事件不并入流式回复.md`

## 背景

长任务存在 Web 已生成完整正文、QQ 未收到最终答复且仍显示输出中的现场。不能仅凭任务完成或曾发送过过程文字，判定最终答复已完整交付；现有现场未保留逐帧回执，不能把所有实例都归为被动消息过期。

## 决策

- QQ 最终正文生成完成后，使用普通主动消息出口，私聊和群聊均不携带入站 `msg_id`。错误提示采用同一独立出口，取消任务不补发最终正文。
- 最终轮生成期间不创建 QQ 流式气泡。Markdown 私聊仍消费实时模型事件并镜像到 Web，但只在确认后续轮/交互暂停时，通过既有普通轮次出口展示过程说明。工具消息与附件策略不变。
- 中间文字保留关联入站消息及平台拒绝后的既有回退策略，不因本 ADR 将全部过程消息改成主动消息。
- 最终出口只发送 `response.text` 与附件，不按 `round_texts` 重放中间正文。历史流的 `stream_sent` 不参与 QQ 最终成功判断，最终发送返回失败必须标记交付失败。
- 旧 QQ 流式发送类和兼容门面保留，便于独立验证与既有调用兼容；生产 IM 调度不再用它发送最终正文。已有客户端悬挂气泡不能在缺少原 `stream_msg_id` 时可靠关闭，本变更不声称追溯修复旧气泡。

## 取舍

最终答复不再逐字出现在 QQ，Web 仍实时展示。普通主动消息仍受平台配额、频控、接收开关及内容审核限制，不是保证送达机制；失败不能伪装成成功，也不能无界重发。保留既有图文渲染、附件处理和受限诊断边界。

本决策替代 ADR-0002 中“所有普通正文均保持被动发送”的最终答复部分，以及 ADR-0006 中“最终正文继续使用流式”的部分；工具与媒体的独立发送规则保持有效。未修改用户运行配置或数据库结构。

## 验证

合成渠道回归覆盖：最终轮生成时不发送、过程消息保留原关联、最终去除关联且只发送一次、历史流已发送不跳过最终、最终失败不标成功、取消不补发、群聊与错误提示一致。测试不向真实 QQ 发送消息，不承诺真实账号的配额或端到端成功率。
