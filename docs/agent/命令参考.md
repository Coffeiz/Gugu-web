# 咕咕命令参考

本文是聊天命令的单一入口，按当前代码行为维护。命令使用半角 `/` 或全角 `／` 均可，命令名不区分大小写。

## 快速表

| 命令 | 作用 | 是否调用模型 | 是否改变状态 |
|---|---|---:|---:|
| `/help` | 显示命令帮助 | 否 | 否 |
| `/stop` | 停止当前正在执行的任务 | 否 | 是，可能取消任务 |
| `/status` | 查看当前执行状态 | 否 | 否 |
| `/compact` | 立即整理当前会话上下文 | 否 | 是，会写入压缩结果 |
| `/memory` | 查看个人长期记忆 | 否 | 否 |
| `/forget <内容>` | 删除匹配的个人记忆 | 否 | 是 |
| `/workspace` | 查看当前会话绑定的工作区 | 否 | 否 |
| `/workspace list` | 列出当前用户可绑定的工作区及 ID | 否 | 否 |
| `/workspace <ID>` | 将当前会话绑定到指定工作区 | 否 | 是 |
| `/workspace 解除` | 解除当前会话的工作区绑定 | 否 | 是 |

## 任务控制

### `/help`

显示当前可用命令。它只返回确定性帮助文本，不会进入 Agent Loop。

别名：`/h`、`/帮助`、`/菜单`、`/命令`

### `/stop`

停止当前会话正在运行的 Agent Loop。没有正在运行的任务时只返回当前空闲状态。

别名：`/s`、`/cancel`、`/x`、`/停`、`/停止`、`/取消`、`/停下`

取消权限按任务发起者隔离：群聊中其他成员不能取消别人的任务。

### `/status`

查看当前状态，例如思考中、搜索中、整理中或等待确认。

别名：`/状态`、`/进度`

## 上下文与记忆

### `/compact`

强制整理当前会话的旧上下文。该命令不启动新的主 Agent Loop，也不等待普通对话触发阈值。

如果当前没有可整理的历史，会返回无需整理。没有会话时不能执行。

别名：`/压缩`、`/整理上下文`

### `/memory`

查看咕咕当前保存的个人记忆，包括个人资料、行为模式和最近状态。命令本身不调用模型、不计入对话精力，也不触发反思。

别名：`/mem`、`/记忆`、`/记得`、`/你记得什么`、`/记得啥`

### `/forget <内容>`

删除与指定内容匹配的个人记忆。例如：

```text
/forget 我喜欢猫
```

匹配支持归一化子串和相似文本。没有匹配项时不会修改任何内容。

别名：`/忘记`、`/忘掉`、`/忘了`

## 工作区与 Shell

Shell 工具默认关闭。要让咕咕执行工作区命令，必须同时满足：

1. Admin 开启 Shell 总开关；
2. 用户在个人设置的工具权限中开启 Shell；
3. 当前会话绑定一个启用中的工作区。

### 查看和绑定

```text
/workspace             查看当前绑定
/workspace list        列出可绑定工作区和 ID
/workspace 12          绑定 ID 为 12 的工作区
/workspace 解除        解除当前绑定
```

`/workspace list` 只返回当前用户自己的启用工作区，不会显示其他用户数据。

绑定工作区不会自动创建目录，也不会自动授权宿主机任意目录。新会话默认不绑定工作区。

### Shell 执行边界

- 只能在当前会话绑定的工作区内执行；`cwd` 只能是相对路径；
- 不支持管道、重定向、命令替换或 `shell=True` 拼接；
- `sudo`、提权、删除、移动、覆盖、服务控制等危险命令需要用户明确确认；
- 超时、输出超限或权限被撤销时会终止整个进程组；
- 同一会话的工作区切换和 Shell 执行严格串行。

## 路由行为说明

命令分为两层：

- **任务路由命令**：`/stop`、`/status`、`/help`、`/compact`，在 Agent Loop 入口前处理；
- **会话控制命令**：`/memory`、`/forget`、`/workspace`，在会话已创建后处理。

这些命令都不会把命令文本交给模型。普通文本、未知的斜杠文本和不完整命令会继续走正常对话流程。

Web、飞书、QQ、微信的消息入口共用会话控制命令处理；具体平台仍需拥有有效会话。`/workspace` 相关命令需要当前会话 ID。

## 当前未提供的命令

以下写法曾出现在早期设计文档，但当前实现不作为正式命令：

- `/workspace use <名称>`：请使用数字 ID；
- `/workspace clear`：请使用 `/workspace 解除`；
- `/newchat`：新建会话由页面按钮或平台会话编排负责。

新增命令时应同时更新：`backend/agent/commands.py`、`backend/agent/router.py`、本文件和 `/help` 文案，并补充命令回归测试。
