## Agent 时间与时区

桌面 Agent 的系统提示、时间工具和日期上下文以运行机器的系统时区为准，每次运行从桌面主机环境读取；用户资料中的时区偏好和续接快照不会覆盖它。Web Host 的 Agent 按用户设置的时区运行。这是两种 Host 的明确适配差异，共享时间工具只消费 Host 提供的可信时区。

## Agent 运行与能力边界

会话、持久 Run、工具契约、记忆规则和搜索能力由共享 Core 提供；Desktop 通过 SQLite、Electron Main 的具名 IPC 和本机文件/网络端口接入，聊天事件投影给共享 UI。记忆正文保存在 `Gugu-data/.agent/memories/`，SQLite 保存会话、Run、回执和检索索引。平台特有的文件访问及 Shell 授权留在 Desktop；Shell 权限不由共享层代管。

桌面 Agent 不注册独立 `read_file` 或回收站/清理工具。拖入或引用的本机文件按授权引用读取；文件清理使用桌面 Shell。普通 `ask_user` 澄清、回答消费和原 Run 恢复复用共享交互契约及 Desktop IPC；`user_sandbox` 授权请求不通过普通澄清工具开放，继续由 Desktop 权限策略负责。共享 `save_attachment` 已适配到本机个人/项目文件目录，使用相对 `folder_path`、不覆盖同名文件，并在本机保存调用回执以支持重放恢复。桌面 SQLite 目前不记录会话工作区绑定，`workspace` 保存目标仍未接通；Web 数字 `folder_id` 在桌面使用相对目录路径表达。本机拖入文件仍按引用处理。桌面能力与待验收项以[迁移任务清单](../../refactor/Gugu-2.0-迁移任务清单.md)为准。

## Agent 邮件

桌面 Agent 复用 Core 的 `send_email` Schema、确认编排和持久投递回执；桌面 Host 通过 Main 进程适配现有邮件账户与 SMTP 发送器。密码由 Electron 主进程使用系统安全存储加密，Core/Worker 只获得脱敏账户信息及本进程内的账户版本标识，发送请求回到 Main 进程执行。确认快照绑定当前发件账户版本、收件人及邮件内容；账户或目标变化时要求重新发起确认。持久发送尝试在访问 SMTP 前认领，结果未知时不自动重发。

当前桌面工具仅在可交互的私聊 Agent Run 中注册，复用 Core 的纯文本、咕咕模板和 HTML 邮件契约。附件只接受当前消息中已授权的本机文件引用，不上传文件或接受模型提供的任意路径；最多 5 个，每个不超过 10 MiB、合计不超过 25 MiB。自定义 HTML 由共享净化器处理，发件前确认绑定账户版本、收件人、邮件内容及附件摘要。发件账户取桌面邮件设置中的首个已连接账户，群聊不注册发信工具。Shell 权限仍由桌面 Host 独立负责，见 [Shell 执行权限](shell.md)。
