# 桌面 Shell 执行权限

桌面工具以工作目录选择执行范围。`cwd=.` 表示在隔离临时目录运行，绝对工作目录表示申请宿主机执行。桌面工具目录不提供 `scope` 参数。

普通模式首次执行宿主机命令时，确认卡展示命令和工作目录。批准后，同一个本地用户与会话在当前 Core 进程中获得 30 分钟执行授权。执行命令不延长授权，Core 重启会清除临时授权。

自动模式下，使用绝对工作目录的宿主机命令直接执行，无需申请 30 分钟会话授权。

宿主进程使用当前操作系统用户权限执行，按原有调用预算限制输出和运行时间。

宿主机权限策略由桌面运行时维护。共享 Core 只提供工具 Schema 构建、确认收据和有期限的会话授权存储机制。Web Host 的策略见其 README。
