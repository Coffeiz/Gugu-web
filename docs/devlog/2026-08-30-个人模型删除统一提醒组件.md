# 开发记录 · 2026-08-30 · 个人模型删除统一提醒组件

## 问题

个人设置中的 BYOK 模型删除操作直接调用浏览器原生 `window.confirm`，导致确认框没有统一的主题、布局和多语言表现。

## 排查

扫描生产 UI 源码后，确认该调用是唯一的浏览器原生确认；其他删除、重置和危险操作已经使用统一的 `confirmDialog`。测试代码中的 `alert(1)` 属于安全测试样例，不属于页面行为。

## 修复

- BYOK 模型删除改用全局 `ConfirmDialog`，保留取消路径并使用 danger 语义。
- 新增中文、日文和英文的删除标题、说明、确认按钮及失败提示文案。
- 新增 UI 回归脚本，扫描生产源码中的 `window/globalThis.alert|confirm|prompt`，并校验 BYOK 删除确认契约。
- 将“危险操作统一使用提醒组件、文案必须 i18n”写入项目开发规范。
