# 开发记录 · 2026-08-30 · 生产构建玻璃模糊属性丢失

## 问题

9595 生产环境的侧栏、咕咕聊天窗口、思维画布抽屉与工具栏、项目编辑卡、定时任务弹窗等多层内容只剩半透明背景，没有 blur；5173 开发环境正常。

## 根因

- 源码同时声明了标准 `backdrop-filter` 和 `-webkit-backdrop-filter`，背景色与主题状态没有异常。
- 当前生产构建使用 Vite 8 的 Lightning CSS 压缩路径，部分规则被折叠为只保留 `-webkit-backdrop-filter`。
- Chrome 的标准 `backdropFilter` 计算值因此变成 `none`，开发环境和旧版 22.0 产物未暴露该问题。
- Nginx 只负责分发静态产物，不是属性丢失的原因。

## 修复

- 在 `frontend/vite.config.js` 中固定 `build.cssMinify: 'esbuild'`，避免压缩器错误折叠兼容属性。
- 不再为 sidebar 或其他单个面板添加临时覆盖规则，统一由构建配置解决。
- 新增 `frontend/scripts/check-css-glass-regression.mjs`，扫描真实 `dist` CSS，检查侧栏、聊天、画布、项目卡、任务弹窗和通用弹出层是否同时保留两种属性。
- 新增 `npm run build:verify`，用于构建后立即执行玻璃材质产物回归。

## 验证

- esbuild 产物统计：标准 `backdrop-filter` 110 条，`-webkit-backdrop-filter` 110 条。
- 9595 已部署验证版本 `prod-local-20260830-r9`，首页返回 200，Nginx 配置检查通过。
- 后续升级 Vite、Rolldown 或 CSS 压缩器时，必须执行 `npm run build:verify`。
