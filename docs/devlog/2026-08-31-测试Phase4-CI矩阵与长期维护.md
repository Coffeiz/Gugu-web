# 测试 Phase 4：CI 矩阵与长期维护

## 变更

- 根目录新增 `test:unit`、`test:integration`、`test:e2e`、`test:all`、`test:affected`、`test:metadata` 和 `test:maintenance` 入口。
- `test:all` 组合后端、前端、Runtime、稳定 E2E、类型检查、构建和静态回归；可用 `--skip-e2e` 在没有浏览器服务的本地环境运行非浏览器完整矩阵。
- `test:affected -- --base=<sha>` 根据变更范围执行后端受影响 L1、前端单测和 Runtime 测试。
- 新增测试元数据门禁，新增测试文件必须登记领域、层级、owner、生产入口、关键回归行为和 CI 入口。
- 新增 skip 策略文件，记录 owner、原因、替代验收路径和到期日期；月度维护入口会阻断失联或过期 skip。
- Runtime integration workflow 改为支持 PR、main push 和手动触发，并增加元数据、边界和失败分类摘要。

## 验证

- 后端全量：`1761 passed`。
- 前端全量：`394 passed`；并行环境下曾出现一次 canvas 时序测试抖动，隔离重跑通过。
- 快速门禁、测试边界、清单生成和 E2E stable/experimental 收集均通过。

## 维护约定

月度执行 `pnpm test:maintenance`，审查测试资产数量、未归类文件、skip 到期、helper 重复和边界白名单；慢测耗时与失败重试由 CI job 摘要保留，不将重试结果冒充首次通过。
