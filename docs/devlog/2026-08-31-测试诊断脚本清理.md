# 测试诊断脚本清理

## 背景

测试资产治理完成后，对 `backend/scripts/diagnostics/` 做一次只删除有证据的清理，避免一次性调试脚本继续被误认为可维护测试入口。

## 本次删除

| 文件 | 处理 | 原因 |
|---|---|---|
| `backend/scripts/diagnostics/minimax_cache_simple_test.py` | 删除 | 与 `minimax_cache_test.py` 职责重复，且没有文档、脚本或测试引用；后者仍是 Minimax 缓存诊断入口。 |
| `backend/scripts/diagnostics/test_simple_valueerror.py` | 删除 | 仅验证基础 `json.dumps` 的一次性调试脚本；相关边界已有 pytest 契约测试覆盖。 |
| `backend/scripts/diagnostics/test_valueerror_debug.py` | 删除 | 只用于一次异常排查，允许读取真实运行数据，不属于可复用测试入口，也没有有效引用。 |

## 保留范围

缓存、上下文、session、schema、Provider 和提醒角色等诊断脚本继续保留。这些脚本仍被开发文档或报告引用，且用于真实 Provider 行为观测，不能因为不进入 CI 就直接删除。
