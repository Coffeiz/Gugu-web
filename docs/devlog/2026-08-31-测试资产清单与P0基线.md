|---|---:|---:|
| Python pytest | 196 | 1698 |
| TypeScript/Node | 15 | 41 |
| Vitest | 57 | 369 |
| Playwright | 10 | 41 |
| 诊断脚本 | 18 | 不适用 |
| 静态检查 | 4 | 不适用 |
| 标准测试声明合计 | 278 | 2149 |

另有 18 个诊断脚本和 4 个静态检查脚本，作为质量资产纳入清单，但不计入标准测试声明数；因此清单资产总数为 300 个。

源码声明数与实际执行数不完全相同：pytest 参数化会展开用例，Vitest 也可能通过组合 API 生成额外用例。因此后续报告必须同时记录“源文件声明数”和“运行器实际收集数”。

边界检查结果：已检查 301 个测试相关文件，未知目录 0 个；3 个文件含实际 `skip`，分别是平台能力不支持或依赖 E2E 环境数据的场景，注释中的 `test.skip()` 不再计入，后续 Phase 3 单独处理。
