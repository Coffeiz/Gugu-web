# 咕咕邮件设计标准 Phase 1

## 变更

- 新增 `email_templates.py`，以语义字段生成 `notification` 和 `test` 两种邮件模板。
- `send_email` 默认使用标准模板，支持标题、预览摘要、正文区块和操作链接。
- HTML 邮件继续附带纯文本 fallback，并由发送服务统一清洗危险标签、链接和不安全样式。
- SMTP 测试邮件复用 `test` 模板；收件人、确认门、个人 SMTP 优先和发送状态逻辑保持不变。
- 更新邮件 Skill，要求模型传递语义字段，不再自行拼接 HTML。
