# 咕咕邮件设计标准 Phase 2

## 变更

- 增加 `reminder`、`report`、`security` 模板，统一邮件外壳、按钮、页脚和纯文本 fallback。
- 密码重置、反馈通知和安全策略告警改用统一模板，移除密码重置调用方的专用 HTML。
- 用户主题模式、主题体系和配色写入用户偏好；邮件服务按模式和配色选择静态令牌，不读取或注入前端 CSS。
- 增加邮件模板主题、配色、结构和危险链接回归检查。
