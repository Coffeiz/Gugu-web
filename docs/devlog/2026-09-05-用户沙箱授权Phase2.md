# 用户沙箱授权 Phase 2：定时任务工作区绑定

## 目标

按 `PRD-SHELL-4` 为独立定时任务增加 workspace 和任务级完整用户沙箱授权。任务绑定 workspace 后覆盖整个 workspace 并从根目录执行；任务授权与创建任务的 Session 授权隔离，默认仍为 `/workspace` 读写、`/personal` 与 `/project` 只读。

## 实现

- `ScheduledTask` 增加 `workspace_id`、`filesystem_authorization_grant_id`，并新增 Alembic 迁移。
- 统一 policy 支持 `scheduled_task` 主体；任务只使用自己的 workspace/grant，不从聊天 Session 继承授权。
- 定时任务 Shell 仅在绑定 workspace 或获得完整授权时注册；任务失效、停用或授权撤销时不回落到默认目录。
- 绑定 workspace 后不再提供独立 cwd；历史 cwd 列通过后续迁移移除，任务统一从 workspace 根目录执行。
- workspace 删除时显式停用并解除绑定的独立任务；触发前仍复核工作区归属和可用根目录。
- 任务 API、Agent 工具、Schedules 表单、公共 `FilesystemAuthorizationDialog.vue` 与 `useFilesystemAuthorization` 已接入。
- OpenAPI 类型通过当前后端 schema 重新生成，未新增目录级授权或宿主机授权入口。
