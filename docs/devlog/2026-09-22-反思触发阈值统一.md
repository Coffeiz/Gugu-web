# 反思触发阈值统一

## 背景

QQ 私聊的 `private-owner` 任务此前在每个 Agent 回合后立即创建，绕过网页/Owner 反思阈值；群级反思使用一小时活跃窗口，群友批反思在 50 条群消息触发，群内 Owner 又使用私聊 Owner 阈值。不同入口的触发语义不一致。

## 调整

- 网页和 Owner/非 Owner 私聊统一使用 `web_private_reflection_threshold`，默认 10，范围 1–100。旧配置 `reflection_threshold` 加载时映射到新字段；不直接改写运行配置文件。
- QQ 私聊将每个已完成 Agent 回合记入 `MemoryReflectionCursor.pending_agent_count`；达到阈值才创建持久反思任务。未达阈值的消息在最后一轮后空闲 3 分钟时由游标收束任务补处理。
- 群 scope 与群友批量任务统一使用 `GROUP_MESSAGE_THRESHOLD=50`；达到阈值时同时调度两类任务。移除群级一小时活跃窗口触发。
- 群内 Owner 缓冲由同群累计 50 条消息的阈值事件冲刷，不单独统计 Owner 发言数，也不读取网页/私聊配置；未到群阈值时仍保留 3 分钟空闲收束。
- 清理 `observe_group_message` 上已无调用者的 `trigger_mode` / `force` 参数及两个旧成员 Agent 路径 no-op 测试；私聊阈值由独立私聊游标路径覆盖。
- 闲置收束成功排队后清除对应累计计数，新消息会重新开启闲置窗口。持久任务仍使用原消息范围幂等键、游标推进和失败重试。
