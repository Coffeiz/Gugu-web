# 系统 Shell 环境说明特例

用户明确批准：管理员和用户双侧开启的系统范围 Shell，需要让模型知道范围与正确调用方式，是工具权限提示词禁令的窄例外。已备注 backend skill；授权事实源仍是执行器，不由提示词授予权限。

现有 Shell 状态说明新增默认 sandbox 与显式 `scope="system"` 的区别，通过共享 `evaluate` 只读判权，双侧开放且策略放行才说明系统范围可用；不会执行探针命令。system 指应用服务所在环境，容器部署不意味着 Docker 宿主机，不代表 root 权限。定时任务不得使用 system。

Web、IM、定时任务复用现有 `extra_reminder` 将状态放在本轮消息区域，不再追加顶层 system，不改变冻结 workspace snapshot。静态 Shell 协议仍按工具可用性追加，因此本次不是完全消除前缀变更；未做真实模型缓存 A/B，不宣称缓存率提升。
