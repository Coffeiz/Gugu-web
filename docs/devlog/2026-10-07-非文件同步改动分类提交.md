# 非文件同步改动分类提交

## 范围

本轮只整理现有非文件同步改动，保留 FS-6 工作区代码、测试、PRD 和接口收口改动，不实施新的同步架构，也不撤回同步实现。

- 文件预览：按事件文件 ID 匹配当前预览，聊天入口读取单文件元数据与地址，重复打开复用缓存。
- 回收站：清空改为持久后台任务，带所有者隔离、全局限并发、唤醒/恢复、进度推送及页面重连补刷。
- Agent：上下文压缩期间保持取消控制，不把主动取消当成压缩失败继续截断或输出错误气泡。
- 数据归档：已删除时间流笔记只保留关系墓碑，不导出标题及正文。
- UI：项目文件夹图标与文件库共用映射；日历周末及范围端点底色；Cafe 亮色背景。
- 部署：分体 Compose 官方镜像签名校验、安全停服、备份与离线迁移入口文档及测试。
- 约定与需求：异步任务推送约定，共享沙盒镜像环境管理 PRD（待实施）。

## 混合改动分离

`app/models/__init__.py` 只提交 TrashPurgeJob，`worker.py` 只提交回收站 Worker 接入；不提交 FileSync 的新模型字段或扫描 Worker。CHANGELOG 只提交上述已实现变化。测试元数据只提交非同步测试登记；旧维护接口删除及其翻译、生成类型与 FS-6 收口有关，留在工作区。

三种语言包中的笔记空状态文案单独提交，旧同步维护文案删除仍留在工作区。

本轮另外补充单文件预览的元数据、已删除拒绝与跨用户拒绝行为测试，避免新的预览入口缺少权限回归覆盖。日历新用例中的日期定位修正为完整月份序列，允许周末范围跨行，不再要求周五至周一位于同一周行。

- 前端完整 Vitest：122 个测试文件、679 项通过（限制为两个并行 Worker）。
- 完整 typecheck、strict typecheck：通过。
- 前端生产构建：通过，产物仅生成于隔离测试目录。
