# 记忆反思原生推理前缀缓存修复

日期：2026-10-13。

场景面板的 7 次反思、416,843 输入、33.4% 缓存率与数据库及 LoopScope 数据一致。低命中由两类请求共同造成：原生快照反思删除主请求恢复的 thinking 块；后台 Owner/群/成员任务从持久历史重建 system/history，未复用工具声明。

本次修复第一类问题：同模型 Anthropic wire 分支保留原生推理块与签名，继续清除外协议 reasoning_content 和孤立工具事件。模型切换的默认历史清洗及续接状态身份校验未改变。

用两条真实 run 数据只读重建请求；恢复深层截断参数与加密签名后，wire digest 均与原 run 精确一致。隔离预热 A/B 的缓存率从 37.9%/0% 提升至 96.2%/96.6%，未命中输入合计减少 95.3%。后台历史重建仍不承诺主请求缓存命中。

两个新增行为回归在修复前失败；本地定向 98 项与 devserver 串行 227 项回归通过。实验未派发工具、未写入记忆、会话、用量账本或用户配置。临时回放探针已清理，运行中服务未重启。

完整实验控制与数据见 [真实 run 缓存 A/B 报告](../reports/OPT-Cache-Strategy-2026-10-13.md)。
