# 文件实时投影删除与替换竞态修复

## 现象与证据边界

用户日志中 QQ 发送返回成功，同一时间 worker 多次报告文件单路径投影 `FileNotFoundError`。只读检查显示绑定仍 active、watcher ready、根目录存在，没有持久化的待核对缺口。

原日志只保存异常类名，缺少堆栈和路径，不能证明某个真实文件就是本次触发源。此次通过隔离数据库和临时目录，复现并修复了能产生相同异常的确定代码缺陷；不能将模拟故障注入说成已还原用户当时的完整现场。

## 根因

`targeted._project_changed_file` 在首次校验与内容哈希后等待数据库查询，再在新建、更新、移动分支重复调用未保护的 `path.stat()`。文件可能在此期间被其他进程删除或原子替换：

- 消失后再次 stat 抛出异常，导致 watcher 回滚并重试整批路径，同批有效文件也被延后。
- 新文件保留原大小与修改时间时，旧实现仍可能将旧内容指纹与替换后的文件元数据组合提交，不能仅依赖大小和修改时间区分文件身份。

## 复现方法

[`test_filesync_phase1.py`](../../backend/tests/storage/filesync/test_filesync_phase1.py) 中新增的行为回归使用内存 SQLite 与临时目录，不连接真实数据库或用户存储：

- 在完整哈希返回后删除文件，覆盖 create/update/move 三分支。
- 在同一时刻将等大小、同修改时间的新 inode 原子替换到目标路径，覆盖同样三分支。
- 同一批包含失效路径与有效文件，验证单个失效事件不会阻止其他文件投影。

修复前上述 7 项全部失败：4 项抛 `FileNotFoundError`，3 项错误提交本应失效的创建/更新/移动结果。移动场景先为同一绑定根建立路径基线，确保真实经过身份复用分支。

追加回归验证手动扫描证据在数据库查询期间失效仍拒绝覆盖，权限错误仍保留 `file_unavailable`，未知异常的重试次数与健康缺口语义保持不变。

## 修改

- 在哈希前捕获文件 stat，在数据库查询后、修改 File 行前重验 device/inode/大小/修改时间。
- 三分支统一使用这次复验得到的 stat，不再在分支中反复读取可能变化的路径。实时路径保留既有根内符号链接的目标大小语义，手动扫描仍使用不跟随链接的复验。
- 普通实时事件已消失或文件已变化时不提交旧 File/journal/配额变更，后续事件继续收敛；已验证的手动扫描证据失效时保留 `file_io` 拒绝，不伪装成完整覆盖。
- 权限及其他实际文件系统错误仍计入拒绝原因，不用吞掉全部 OSError 的方式隐藏故障。
- watcher 未知异常补充受限 `diag_log` 堆栈，普通日志继续只记录绑定与异常类型，不输出文件名、路径或正文。

保留现有权限、配额、重试上限与缺口修复策略，未引入全树扫描或新轮询。此次重验保护的是读取与数据库等待之间的窗口，不承诺文件系统与数据库跨进程事务原子性；后续发生的文件变更仍依赖监听事件及既有核对机制收敛。

## 实际 Shell 链路

扩展 [`test_filesync_live_shell.py`](../../backend/tests/storage/filesync/test_filesync_live_shell.py)，使用真实 `/bin/sh`、TS sidecar 和多连接临时 SQLite：

- 新建、等长覆盖、删除原有单文件场景仍通过。
- 同一目录连续 12 轮原子替换，穿插短命文件创建/删除，最终写入固定正文。
- 检查最终 File 大小、journal SHA-256 与磁盘最终正文一致，短命文件没有活动记录，全程没有捕获到投影异常。

独立链路测试通过；一次观察的新建、等长修改、删除延迟约为 1483ms、1121ms、219ms。它们只是该次测试环境的观测，不是性能承诺。

## 验证命令

均在 devserver 串行执行：

```bash
cd backend
PYTHONPATH=. .venv/bin/pytest -q tests/storage/filesync/test_filesync_phase1.py \
  -k 'changes_after_hash or disappearing_file_does_not_abort' --tb=short
PYTHONPATH=. .venv/bin/pytest -q tests/storage/filesync/test_filesync_phase1.py --tb=short
PYTHONPATH=. .venv/bin/pytest -q -s tests/storage/filesync/test_filesync_live_shell.py --tb=short
PYTHONPATH=. .venv/bin/pytest -q tests/storage/filesync --tb=short
```

结果：定向复现修复后 7 项通过；核心投影与边界 55 项通过；实际 Shell 链路 1 项通过。补充根内符号链接兼容性测试后，最终整组文件同步回归 176 项全部通过，用时 175.97 秒。

测试仅在 pytest 临时目录写入，没有修改运行配置或真实用户文件；没有向 QQ 发消息，也没有植入运行时探针。代码同步用于隔离测试，常驻服务尚未重启，改动保留在工作区待用户确认。
