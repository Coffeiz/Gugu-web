# QQ 最终答复主动交付

## 改动

- QQ 私聊 Markdown 的模型事件继续实时镜像到 Web；QQ 仅在工具续轮或交互暂停边界发送已完成的过程正文，最终轮不创建流式气泡。
- QQ 私聊、兼容格式和群聊的最终正文统一走普通主动消息，保持现有图文、附件发送管线。只发送最终 `response.text`，不重放 `round_texts`。
- 最终出站返回值独立决定成功或失败，历史 `stream_sent` 不再绕过 QQ 最终发送。错误提示同样主动发送，取消任务不补发；缺少模型终态时不制造成功响应。
- 保留旧 QQ 流式模块与兼容门面，不改动用户运行配置或数据库结构。已有悬挂气泡无法在缺少原流标识时可靠关闭，本次只防止新调度创建这种长期流。
