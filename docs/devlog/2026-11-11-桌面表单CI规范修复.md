# 桌面表单 CI 规范修复

## 问题与原因

[PR #116](https://github.com/Coffeiz/Gugu-web/pull/116) 首次运行 Runtime integration 时，前端单测有 981 项通过、1 项失败。全站 `field-label-focus` 检查发现桌面工作台的项目、联系人输入使用 `label for`，违反字段标题不得激活文本输入控件的既有交互规范。桌面组件定向测试没有覆盖这项全站约束。

## 修复

把标题改为非交互元素，通过 `aria-labelledby` 保留输入框的可访问名称。输入框改用公共 `.form-input`，移除页面重复的外观和焦点样式；页面只维护尺寸布局。没有修改既有测试断言、跳过测试或放宽规范。

## 验证

隔离前端环境执行桌面组件测试和全站字段标题测试，合计 3 项通过；桌面入口构建、普通与严格类型检查通过。最终两条 CI 以 PR 正文记录的同一最新提交为准，首次失败记录保留。

这项既有全站测试能拦截任何 Vue 页面新增的可点击文本输入标题，不绑定桌面组件的实现细节；无需重复新增同类源码扫描。
