# Node 26 与项目/日历 Vite 隔离 PostgreSQL 验收

## 结论

devserver 已安装 Node.js 26.13.1；Vite 与 Node Host 进程均由该版本启动，无需再次升级系统运行时。Vite 转发到 Node Host 的项目更新、日历创建、项目删除与恢复路径已通过认证 HTTP 集成验证。

## 验证

- 测试在 devserver 使用 Node 26.13.1 执行，不使用 Docker。
- 一次性 Vite 代理连接到 Fastify Host，并使用合成用户与随机 PostgreSQL schema；未认证项目 PATCH 返回 401，认证 PATCH、日历 POST、项目 DELETE、restore 分别返回 200、201、204、200。
- 直接检查项目与关联日历事件的删除/恢复状态、版本号和 Undo 记录，并检查日历 RAG job 在 post-commit live event 前已经持久化。
- 首轮测试发现事件恢复版本的测试预期错误；按删除与恢复各递增一次的行为修正后，集成测试 1/1 通过。测试结束后关闭服务、连接池并删除随机 schema。
- 项目/日历/Host 定向 Node 套件在 devserver 重跑 **114/114**，0 跳过，包含隔离 schema PostgreSQL 用例；对应 Python pytest 串行重跑 **67/67**。独立 Vite HTTP 集成测试再次 **1/1** 通过。
- `corepack pnpm run typecheck` 与 `corepack pnpm run build` 均通过；实际 Vite 首页、Node Host readiness 返回 200，Vite 未认证 `/auth/me` 返回 401。

## 边界

该验收只覆盖项目 PATCH/DELETE/restore 和日历创建切片，不代表 Node WebUI 全量迁移完成；Redis 跨进程通知和 RAG Worker 消费不在本次 HTTP 测试范围内。
