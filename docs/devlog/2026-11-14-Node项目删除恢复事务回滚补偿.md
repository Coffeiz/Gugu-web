# Node 项目删除与恢复事务回滚补偿

## 变更

项目 DELETE/restore 会在 PostgreSQL 事务中移动 Local 文件。若数据库事务在文件移动后失败，数据库会回滚但文件系统不会；这会让文件记录与实际路径不一致。

现在 Local 存储适配器为成功移动返回反向补偿操作。DELETE/restore 的事务失败时，应用层按相反顺序撤销已完成的文件移动；补偿失败时返回安全的 busy 错误。越界路径、符号链接等安全错误仍中止删除，普通物理移动错误继续保持 Python 兼容语义。

- 新增行为覆盖：DELETE/restore 提交失败时文件回到对应路径、数据库保持回滚状态且不发布事件；Local 存储回调对真实临时文件完成正反向移动。
