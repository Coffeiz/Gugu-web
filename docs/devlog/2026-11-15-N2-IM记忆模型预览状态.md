# N2 IM 记忆模型预览状态

新增 `GET /api/v1/admin/agent/memory/im-scopes/maintenance/model-preview/status`，真实消费者为 Vue `useImMemoryMaintenance.ts`。Python 基线是 `agent_admin.im_memory_model_preview_status()`，仅读取固定 Redis key `im_memory:maintenance:model_preview`，不启动模型、预览或记忆维护。

复用已有 Core `maintenance/admin-status.ts` 和目标 Host `modules/admin/maintenance-status.ts` 最小增量，无新组合根能力。空值完整返回 status=idle、done=0、total=0、needs_review=0、failed=0、plan_ready=false；存在的 JSON 原样返回，坏 JSON 保持 Python 的错误语义，不像其他维护状态那样转换 idle。Redis 未配置或传输故障明确 503，坏 JSON 则由统一安全错误处理返回 500，不回显原始内容。

## 边界

状态生产者仍为 Python 的模型预览任务，本接口不代表预览启动、模型调用或计划应用已迁移，也不扫描或读取真实 scope 记忆。本切片不需要业务 PG/SQLite 适配，PG 仅用于 Host 认证审计的隔离精简表。未连接用户 Redis、真实模型或用户记忆；真实部署未验收。未修改 Python 参考后端，未提交或推送。
