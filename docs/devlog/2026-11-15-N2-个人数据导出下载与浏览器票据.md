# N2 个人数据导出下载与浏览器票据

新增完整下载闭环，而非只签发没有消费者的票据：

- `GET /api/v1/data-portability/exports/{job_id}/download`
- `POST /api/v1/data-portability/exports/{job_id}/download-ticket`
- `GET /api/v1/data-portability/exports/{job_id}/download/browser`

真实消费者为 Vue data-portability 下载请求和浏览器原生大文件下载。Python 基线为 `data_portability._stream_export()`、票据签发/验证、`crypto_stream.EncryptedArchiveReader`，产物来自既有 Python Worker。

## 实现和安全边界

Core `data-portability/archive-reader-node.ts` 兼容 Python GUGUPV1 容器：HKDF-SHA256 派生包裹密钥、AES-GCM 解出数据密钥，再按 1 MiB 分块认证解密；验证 magic、context、footer 和密文布局。`download-export-node.ts` 执行 owner/ready/未过期查询，读取完整密文校验大小及 SHA-256，之后按 Range 输出认证明文。正常下载不落明文临时文件，不更新任务或删除归档。Range 包括尾缀、开区间和边界校验，响应保持 200/206/416、Content-Range、Content-Length、ZIP 文件名、no-store 和 nosniff 语义。

Host 直接使用稳定 `openLocalFile` 打开受控存储根内私有归档，管理文件句柄、HTTP 流与断连清理。下载所用 Host secret 必须与 Python 生成归档使用的系统 secret 一致；本次只使用合成密钥验证，未读取或搬运真实运行配置。共享 FS 原语的所有平台和并发目录替换边界未在本切片重新验收。

票据 HMAC 绑定 owner、job 和到期秒数；120 秒、HttpOnly、SameSite=Lax、限下载路径，HTTPS 下附加 Secure。响应 URL 保持同源相对路径，不含票据或登录 token。与 Python 相同，票据在有效期内可重复使用，签发时检查任务 ready/未过期；浏览器消费不要求同时携带登录 JWT，但每次仍验证票据和数据库 owner/任务状态。登录态下载仍走真实用户认证。
