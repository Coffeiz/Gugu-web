- `GET /api/v1/admin/audit-log`：基线为 `backend/app/api/v1/audit_log.py:list_audit_logs`（Python 实际注册路径没有末尾斜杠）。Web 管理员认证后调用 Core `admin/audit-log.ts`，使用生产 Host 注入的 PostgreSQL 查询。默认上限 200、零上限返回空集；负数保留数据库拒绝语义并由 Host 隐藏内部异常。仅投影公开字段，UTC 时间保留微秒。
