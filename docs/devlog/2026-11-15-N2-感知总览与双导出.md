## Python 基线与契约

基线为 `backend/app/api/v1/agent_perception.py`、`agent/memory/reflection.py` 的 `_perc_rec/_fb_rec/_misperc_llm/_emit_perc` 及 `agent/memory/store.py::read_misread`。

总览保留默认 168 小时、20000 条原始 Redis 截取、活跃门槛与开发者筛选。先按用户平均，再对用户做宏平均；缺失数字不补零，bool 按 Python 数值处理。misperc 总条数包含未配对项，但误判率只将同用户事件配到前一轮 perc；类别分“感知误读”和全部纠正。两阶段均值、比例和 flag 使用实际 IEEE754 比值的 Python 偶数舍入，保留 flag 文案里的浮点表示。无活跃用户时不额外增加 Python 原本没有的 flag_items。

Python 的 set 使等比分组和跨用户并列项本就没有固定次序。差分测试在这些并列身份行上规范化后比较完整字段，并独立断言占比排名；没有删除指标或放宽数值断言。

导出默认 hours=0 为全部，含时间窗边界、缺失时间默认为 0、相同时间保持原顺序；附件名和 UTF8 媒体类型保留。Host 复用本业务的 Pydantic 整数解析，保留巨整数；总览响应的大整数通过 Node 26 JSON.rawJSON 输出为 JSON number，Redis LRANGE 参数保留 bigint，不将其误当空快照。非有限阈值及无法转换的巨时间窗仍为错误。

Markdown 使用 Python strip 空白集合；缺失或空文档才返回原空文案，损坏 UTF8 采用替换解码。**安全差异**：Python 存储 `_read` 会吞所有 IO 异常；目标入口将权限等意外 IO 错误经统一 500 脱敏，避免把实际故障伪装成“暂无”。符号链接被现有目标只读能力拒绝，不读取授权根之外文件。
