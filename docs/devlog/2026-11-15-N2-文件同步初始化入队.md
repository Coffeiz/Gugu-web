# N2 文件同步初始化入队

`POST /api/v1/admin/filesync/bindings/{binding_id}/initialize` 对照 Python `binding_initialize`、`enqueue_reconcile_run` 和 runner 初始化测试。Host 要求管理员认证、显式确认，并拒绝 `allow_delete`；Core 复用 dry-run 的绑定行锁、快照、排队幂等与提交后事件，仅将 action 改为 initialize，禁止删除。

先写 Host 行为测试并在 devserver 观察目标模块缺失失败；实现后 Node 定向回归 4/4，包括原 dry-run 2 项、初始化认证/确认以及真实隔离 PG 中 Node 入队后由 Python runner 实际导入合成文件。Python 原初始化 runner 测试 1/1。上述四个被测文件本地与 devserver SHA-256 一致。Core 入队行为测试是在路由红灯之后添加，并未单独记录 Core 缺失红灯，不将其说成独立红绿循环。

测试使用随机 schema、隔离 Redis、临时配置和合成文件。此接口已由主会话接入生产组合根；真实生产 Host 的组合回归、完整 Alembic 升级、正式 SQLite、Node Worker 和真实部署未验收。未修改 Python 参考实现、真实配置或用户数据，未提交推送。
