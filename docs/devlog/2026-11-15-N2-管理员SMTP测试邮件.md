# N2 管理员 SMTP 测试邮件

## 接口与调用链

- `POST /api/v1/admin/config/test-smtp`；真实调用方为 `apps/web/src/views/Admin/Config/index.vue` 的 `testSmtp`。
- Python 基线：`backend/app/api/v1/config.py` 的 `SmtpTestParams/test_smtp`；`app/services/email/__init__.py` 的 `send_test_email → _resolve_from → _build_msg → _deliver`。
- 新目标链路：Host `modules/admin/smtp-probe.ts` 负责认证/DTO/动态只读配置，Core `email/smtp-test.ts` 负责参数回退、固定邮件完整内容与结果，Host `adapters/smtp-test-delivery.ts` 通过现有 nodemailer 实际 SMTP 发送。
- 复用 Core 完整 `renderEmailPreview`，只对固定测试邮件输出转换 CID/邮件 CSS 白名单；该转换不接受用户 HTML，不代替通用净化器。不修改其他会话的邮件 renderer/邮件服务、旧用户 SMTP 实现或 Python。
- `providers/transport/node.ts` 唯一增量为导出已有 `environmentCa`，SMTP 与 Provider 共用正式 CA 读取规则，原有调用行为未改。

## 行为

- 每请求读取 SMTP JSON 环境配置、大小写不敏感的 `SMTP__字段`、配置文件 `smtp` 段，优先级依次升高；文件字段显式空串保留，读取失败拒绝继续。请求非空字段覆盖有效配置。
- 端口零值回退配置；请求省略 `use_ssl` 始终使用 Python 默认 `true`，不继承配置中的 `use_ssl`。`false` 必须升级 STARTTLS，不允许降为明文发送。
- 空 user 不认证；非空 user 使用请求密码或已存密码。发件人非地址字段作为显示名，地址回退 user；测试收件人优先于通知收件人。
- 缺 host/收件人返回 Python 相同 `{ok:false,message}`；成功返回相同收件人提示。
- 保留完整 multipart alternative/related、中文主题/显示名、纯文本、邮件 HTML、两个 CID/文件名和 PNG。随机 MIME boundary、Date、Message-ID、传输编码无须逐字相同。
- 主动安全差异：SMTP 异常返回固定中文失败说明，隐藏认证服务回显/路径/凭据；损坏/非法配置返回脱敏 503，不沿用 Python 原始异常外泄。含 CR/LF 的邮件头拒绝发送。
