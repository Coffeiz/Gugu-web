# N2：管理员完整邮件预览

## 范围与真实调用方

新增 `POST /api/v1/admin/email/preview`。`apps/web/src/views/Admin/Email/index.vue` 的 `refreshPreview` 经管理员认证请求该接口，并消费 `html`；响应同时保留 Python 的 `plain`。没有修改前端、旧 Host SMTP 预览、Python 后端或共享邮件发送实现。

Core `email/preview.ts` 承担完整语义模板、文本转义、链接限制、主题色板与纯文本渲染；Host `modules/admin/email-preview.ts` 承担管理员鉴权、草稿和翻译 DTO 校验、422/400 协议映射。主会话接入生产 app/main 和包导出。

基线为 `backend/app/api/v1/email_admin.py` 的 `EmailDraft`、`preview_email` 与 `backend/app/services/email/templates.py`。预览忽略 translations 的内容，但仍校验其语言和完整字段；subject/title/body 按 Pydantic 先长度校验再去空白，区块和操作另由 renderer 校验非空。没有用固定示例邮件代替草稿。

## 图片资源

Python 使用 PIL 将两张现有 PNG 的 alpha 叠上品牌色。`compat/support/generate_email_preview_assets.py` 在 devserver 调用同一 `_asset_payload`，生成 20 张确定性着色 PNG 的静态 base64 表 `email/preview-assets.ts`，无需生产 Python/PIL 或磁盘读取。文件约 1.1 MB，原图 SHA-256 记录在生成文件头；没有增加图片处理依赖。Python 原图或着色算法变动时应重跑生成器和差分测试。

完整 HTML、纯文本及两张内嵌 PNG 的输出均逐字节比较：10 种主题色板、5 种模板、空白字段；没有只比较颜色或图片数量。预览使用 data URI，与实际发送邮件的 CID 格式不同；本切片不声明发送能力。
