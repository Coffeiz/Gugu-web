# 管理员模型目录与安全传输

## 范围和实际调用链

接入三个 `agent_admin.py` 接口：`GET /api/v1/admin/agent/llm-presets/{preset_id}/models`、`POST /api/v1/admin/agent/llm-presets/models-preview`、`POST /api/v1/admin/agent/voice-presets/models-preview`。前端模型及语音配置表单实际调用；生产链路为 Admin guard → Host DTO → Core 配置/凭据用例 → 共享 Provider 请求构建 → Host 安全 Node HTTP transport → 上游目录。每次请求取消响应并关闭 transport，不发送聊天或 ASR 请求，不调用付费服务。

Core 新模块 `agent/config/admin-model-directory.ts` 和 `llm-model-directory.ts`，Host 新模块 `modules/admin/llm-model-directory.ts`；不依赖旧 Host domains 转发，不修改共享 Provider。Python handler 读取原始 override 文档，而非 `get_settings`：保存预设只传 provider/base/key/api_format 四字段；preview 忽略 local_runtime，且不会写配置或迁入旧配置。main 逐请求读取同一可信配置文件，没有 env 覆盖保存预设的问题。显式语音 key 可绕过保存预设读取；复用保存 key 时必须精确匹配 provider 和去除尾斜线的目的地，错误在网络请求前拒绝。

## TDD 与对照

测试均在 devserver，使用合成数据、临时配置、随机 PostgreSQL schema 与临时 HTTP 服务。

- Core 目录模块、Host 路由和配置用例分别先因缺模块失败，再实现后定向 2/2 通过；目录测试与真实 Python handler / HTTPX 协议构建比较完整响应及请求。
- 15 组真实 Python 对照覆盖 OpenAI/Anthropic/MiMo/Qwen/Local/Ollama、去重、Unicode 码点排序、list/dict/float/巨整数模型 ID 的 Python 字符串表示、401/429/500、非法 JSON、无效或对象 data、资源取消及关闭。
- 共享 diagnostic 原始请求与 Python 的差分先证实 Ollama native 多带 Authorization。仅在本用例按 Python 四字段契约丢弃 native 未使用凭据并移除该头，不更改共享 Provider。非默认测试 `llm-models-provider-parity.blocked.ts` 保留原始差分，不参与默认测试收集；它不是当前新 API 的待修失败。
- 非字符串模型 ID 起初被 JS 转成 `[object Object]` / 逗号字符串，有效红灯后加入目录专用 codec；数字保留原 JSON token，避免巨整数精度丢失、float 整数化和指数格式差异。Qwen 原生地址带尾斜线的实际 Python 对照也先失败，再按原顺序去尾斜线并切换同域兼容目录，未放宽断言。
- 原 Python pytest 串行 5/5：保存预设目录四参数、preview 不传 runtime、语音凭据目的地、原生同域目录、上游鉴权错误脱敏。

定向测试：`tests/admin/config/llm/models.test.ts`、`llm-model-directory-routes.test.ts`。生产测试：`tests/host/main/admin/models.integration.test.ts`，真实 Admin 登录、普通用户 DB 鉴权、真实安全传输、配置热读、配置不落盘和拒绝云请求访问回环地址均已通过。与 QQ 扫码生产合批 2/2，通过一次统一 Core build 和 Host typecheck；QQ 普通用户接口的 SQLite 范围另由其切片记录，本 Admin 目录验收不外推。

## 边界

不放宽共享 DNS、URL、凭据、重定向或显式 Local 出口策略。普通云配置即使指向回环地址也不能借用 Local 出口；与旧 Python 直接 HTTPX 的宽松网络能力有意区别。保留共享 JSON 响应体 64 MiB 上限。配置腐坏返回安全 503，Python 原 RuntimeError 为 500；缺失文件按空文档读取。目录不证明模型可执行、媒体能力或 Agent 完整闭环，也不证明外部 Provider/真实部署可用。Admin 接口验收范围为 Linux/NAS Web + PostgreSQL，不要求桌面 IPC/SQLite。

未修改 Python 参考后端，保留全部其他会话未提交修改；未提交、推送、fetch 或触发 CI。
