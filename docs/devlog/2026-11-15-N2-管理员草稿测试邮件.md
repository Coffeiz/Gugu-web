# N2 管理员草稿测试邮件

## 接口与实际行为

`POST /api/v1/admin/email/test` 有真实调用方：`apps/web/src/views/Admin/Email/index.vue` 的 `sendTest`。与管理员 SMTP 连通测试不同，此接口发送当前草稿及指定语言，不批量发布。

Python 基线为 `backend/app/api/v1/email_admin.py` 的 `EmailTestRequest → _content_for_locale → test_email`，实际邮件调用 `app.services.email.send_email_with_status → _build_msg → _deliver`；已阅读原 `tests/platform/admin/test_email_admin.py` 及模板/附件回归。

新链路由 Host `modules/admin/email-test.ts` 验证管理员和 DTO，Core `email/test-delivery.ts` 选择语言及发送规则，复用现有完整模板和 Host 真实 SMTP 适配。SMTP 配置每请求读取，收件人来自请求，不使用通知收件人或 SMTP 测试默认收件人。

- `zh-CN` 始终使用源内容；其他语言有翻译则使用翻译，否则回退源内容。未选中的语言不会发送。
- 保留五模板、两主题、五色板及完整 CID 图像。纯文本按 Python 此接口的真实行为只含选中语言的 `body`，与 SMTP 连通测试的 sections/actions 完整纯文本有意区别。
- 成功响应为 `{ok:true,status:'sent',delivery:'smtp_accepted',message:'SMTP 已接受邮件'}`，不声称最终送达。
- 缺 SMTP 为 `smtp_not_configured`，TLS/认证及发送失败返回对应安全状态，禁止明文降级。空 user 不认证。
- 草稿字段长度、sections/actions 数量、翻译语言、收件人格式和长度在发送前校验，越界 422；认证在校验及发送之前。
- 主动安全差异：换行邮件头拒绝发送；损坏配置返回脱敏 503。Python 某些邮件头构造异常会直接外溢，本实现不会向管理员暴露原始异常或凭据。

## 最小复用改动

- 仅把本会话新增的 `smtp-test.ts` 中受控模板到邮件 MIME 载荷适配提取为 `renderSmtpDraftMessage`，不接受任意 HTML；原固定 SMTP 测试邮件继续调用同一实现。
- 复用完整 `renderEmailPreview`，不修改 renderer。HTML/CSS 和 CID 转换经过真实 Python `_build_msg` 全字段比较。
- `email-preview.ts` 仅为现有 DTO 校验函数增加 export；`admin/email-recipient-count.ts` 仅为同一邮箱正则增加 export，已有行为不变。
- 动态 SMTP 读取在本会话新增模块内提取复用；TLS 适配统一抛出脱敏分类错误，不修改其他用户 SMTP 实现。
