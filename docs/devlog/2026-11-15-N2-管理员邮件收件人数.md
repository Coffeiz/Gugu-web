# N2 管理员邮件收件人数

新增 `GET /api/v1/admin/email/recipient-count`，实际消费者为 Vue Admin/Email 的 `loadCount()`。Python 基线为 `email_admin.recipient_count()`、`_active_recipient_emails()` 以及 `services/email/queries.get_active_recipient_rows()`。

Core `admin/email-recipient-count.ts` 直接查询 active、account_status=active、email_subscribed=true 的用户并左连接偏好。邮箱按 Python 的 strip 和空白规则校验；只对有效邮箱计数，不去重或发送。偏好 JSON 不存在、损坏或非对象时使用中文，合法 en-US/ja-JP 分别计入对应组。Host `modules/admin/email-recipient-count.ts` 负责管理员认证和 HTTP 接线。公开响应仅含总数及三种 locale 计数，不返回邮箱。
