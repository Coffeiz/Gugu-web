# N2 终端持久视图删除

## 范围与真实行为

`DELETE /api/v1/terminals/{terminal_id}` 基线为 Python `terminals.py:delete_terminal_view`、`app/services/terminals.py:get_terminal/delete_terminal` 及 `agent/terminal/access.py:authorize_operation`。

该接口只删除持久终端视图和可重放事件，不调用PTY manager，不终止执行进程；Node保留这个范围，不能描述为终端执行生命周期完成。DELETE分支在owner及关联会话校验后直接允许清理，明确不要求Shell capability、Docker或MXC readiness，权限撤销后用户仍可清理自己的视图。

前端 `terminalApi.delete` 有实际调用，已有Node Live资源集合支持terminals/delete。列表、创建、运行、重开及WebSocket尚有独立依赖，不能从本接口推断完整终端页面已可用。

## 目标调用链

Core `terminals/delete.ts` 在事务内锁定同owner终端；没有返回404。关联session非空时必须存在且同owner，否则403「终端会话不存在」。显式删除terminal_events再删terminal_sessions，不依赖数据库外键自动级联。事务成功后才发布变更，通知故障不回滚删除。

Host `modules/terminals/delete.ts` 提供认证、可信owner和客户端origin。生产根注入既有Redis publisher，事件精确为resource=terminals、operation=delete、entity_id=terminalId及原X-Client-Id origin；不把终端名称或输出放入变更事件。
