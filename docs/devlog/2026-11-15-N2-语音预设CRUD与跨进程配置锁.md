# N2 语音预设 CRUD 与跨进程配置锁

在只读列表后新增五个真实 Admin 调用入口：

- `POST /api/v1/admin/agent/voice-presets`
- `PUT /api/v1/admin/agent/voice-presets/{preset_id}`
- `DELETE /api/v1/admin/agent/voice-presets/{preset_id}`
- `POST /api/v1/admin/agent/voice-presets/{preset_id}/activate`
- `POST /api/v1/admin/agent/voice-presets/deactivate`

真实调用方是 `useVoicePresets` 的保存、删除与激活操作。没有接入模型列表探测、试呼或真实Provider。

## 基线和边界

Python基线为 `agent_admin.py` 的五个预设 handler、`VoicePresetPayload/Update`、`_validate_voice_provider_format`、目的地Key复用校验、`agent/voice_config.py:dashscope_service_for_model` 和 `config.py:mutate_override_json`。

Core `agent/config/voice-presets-mutate.ts` 承载校验和完整用例。创建首项或当前无活动项时激活新项；删除活动项清空active_id，不自动选择其他项；停用保留所有预设。空/省略API Key保留旧值，服务商/目的地改变须重新提交Key；原生百炼产品线由模型重新推导。校验失败不发布配置，响应只含掩码。

Host `modules/admin/voice-presets-mutate.ts` 建立管理员认证、DTO传递、错误映射及平台接线。Node26 FFI的原有实际flock实现最小提取到 `adapters/posix-config-lock.ts`，旧调用方导出同一实现；新功能不依赖旧domains转发。`config-override-file.ts` 仅追加持锁mutate入口：持Python同一inode锁读取最新文件、调用同步业务变更并复用已有原子替换/fsync，不覆盖其他配置段。既有未提交修改保持原样。

有意的数据保护差异：Node写入口拒绝缺失/坏JSON文件，也拒绝坏预设集合，不像Python `_ensure_voice_presets` 将它重置为空集合后写回。分别返回固定脱敏503或422，不创建用户运行配置。成功API只改变voice_presets；测试全部使用临时文件，不操作真实用户配置。提交后目录fsync等I/O错误仍可能属于未知提交结果，本回归的“失败不写”专指校验/读取失败。
