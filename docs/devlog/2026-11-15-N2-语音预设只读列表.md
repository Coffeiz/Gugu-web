# N2 语音预设只读列表

本文保留只读切片的阶段证据；后续CRUD进展见 [语音预设CRUD与跨进程配置锁](2026-11-15-N2-语音预设CRUD与跨进程配置锁.md)。

新增 `GET /api/v1/admin/agent/voice-presets`。真实调用方是 Admin 的 `useVoicePresets.load()`；读取生效配置文件中的 `voice_presets`，返回 active_id、预设字段、密钥掩码、has_api_key 与 active。只迁移列表，不迁移创建、修改、删除、激活、模型探测或语音执行器。

Python 基线为 `agent_admin.py:list_voice_presets/_ensure_voice_presets/_voice_preset_response/_mask_key`。Core `agent/config/voice-presets-read.ts` 执行投影；Host `modules/admin/voice-presets-read.ts` 建立管理员鉴权与配置文件读取。每次请求只读最新文件，不创建、重写或修复运行配置；缺失或无效预设集合返回空列表，非对象列表项跳过。规范预设字段按 Python 行为投影，不把任意损坏的非字符串字段转换宣称为完整 schema 验收。

既有 Host `shared/secret-mask.ts` 修改前没有未提交差异。为避免新API依赖旧业务目录，只将纯遮蔽契约最小提取至 Core `shared/secret-mask.ts`，原 Host 导出共享函数；按 Python Unicode码点计数，避免 emoji 被UTF16长度重复遮蔽。已有ASCII行为不变。
