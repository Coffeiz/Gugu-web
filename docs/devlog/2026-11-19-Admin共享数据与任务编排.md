# Admin 共享数据与任务编排

> 后续边界调整：独立 Admin 包已撤销，所述实现现归入 `apps/web-host/src/modules/admin/`；本记录保留当时的实现和验证经过。

`@gugu/admin` 接收可信服务端注入的身份边界、事务、Redis 命令、存储、Provider 和时间能力。用户冻结/解冻的状态用例与 PostgreSQL 行锁/更新迁入共享包，Web Host 保留管理员认证、冻结确认和同连接事务装配；提交后仍先发布认证状态，再写入审计。Agent 用量统计与 PostgreSQL 查询迁入共享包，HTTP 参数映射和时区能力仍由 Host 提供。

IM 记忆预览与应用、账号记忆清理、索引和 Embedding 批次、存储配额核对的既有编排及 Redis 状态操作迁入共享包。本地文件、PG/RAG 读写、Provider 与 Worker 生命周期仍由 Host 注入；索引重建和 Embedding 重建沿用原有全局键、锁与状态协议，并未新增持久 fencing、租户隔离或跨版本恢复。SaaS 管理范围、数据模型及其授权须独立设计，现有全局查询不得用作租户隔离。

验证：Admin 构建及类型检查、Web Host 生产源码类型检查与冻结锁文件检查通过。定向回归 41 项中 39 项通过、2 项因没有隔离 PostgreSQL 跳过；其中使用独立临时 Redis 验证租约竞争及配额状态，并在完成后关闭服务、删除临时目录。其中账号记忆清理用注入端口的空计划覆盖预览、应用和租约释放；未连接真实业务数据库，未验证 SaaS 租户隔离及部署。
