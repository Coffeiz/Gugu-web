# MiniMax 流式错位增量

devserver 的 IM Run 收到 HTTP 200 后，在 Anthropic 兼容流的思考块里收到 `input_json_delta`。Node 将这个组合判为协议错误，任务在工具执行前结束。

旧 Python 后端将流交给 Anthropic SDK 解析。SDK 只对支持工具输入的块累积 `input_json_delta`，思考块上的同类事件会被跳过。Node 在 MiniMax 兼容路径采用同样的规则，后续工具参数继续由其对应的工具块解析。

回归用合成流验证错位增量后仍能产出完整工具调用，工具参数只来自工具块，且请求只发送一次。标准 Anthropic 路径继续报告该协议错误。
