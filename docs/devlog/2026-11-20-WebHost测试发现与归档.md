# Web Host 测试发现与定时任务归档

Web Host 将递归 glob 交给 Node test runner 展开。普通 shell 原先只选中一层目录下的 698 个文件。按递归方式可发现 810 个，补进 112 个嵌套测试文件。

定时任务的 30 个文件按路由、授权、调度、执行、投递和存储归档。断言、夹具行为与已有测试元数据的分类保持原样。PostgreSQL 和集成环境相关的文件使用点分后缀。

| 验证范围 | 结果 |
| --- | --- |
| 原先漏跑的 112 个文件，macOS，无外部依赖 | 680 项，545 通过、10 失败、125 跳过 |
| 定时任务，隔离 PostgreSQL 与 Redis，搬迁前后 | 均为 80 项，73 通过、4 失败、3 跳过 |

漏跑批次的 10 项失败来自 IM 附件和记忆写入使用的 Linux 文件系统能力。定时任务的已知失败涉及 MCP 测试表缺少字段、执行授权结果差异及一次性和周期 Worker 投递超时。两次定时任务运行的失败用例一致。这些结果作为后续整理的基线。
