# 共享文件工具装配

Web 和已认证 IM owner 私聊共用 Shell、图片查看与磁盘回收站的装配入口。两端使用相同的沙箱快照、挂载规则和回收站实现。会话授权与确认通过宿主传入，执行时仍检查当前运行租约、文件范围和一次性确认收据。

devserver 的磁盘回归通过共享装配验证路径越界拒绝、确认前文件变更拒绝、删除、列出、恢复和永久删除。Desktop 侧车、上下文与记忆编排、Gateway 调度的跨端统一属于后续迁移。

通用 owner 工具注册表已下沉到 Core。Web Host 的注册入口继续提供原有的项目创建幂等键和配置白名单。Core 注册表接受宿主提供的授权、存储与确认端口，Desktop 可通过同一接口装配本地端口。
