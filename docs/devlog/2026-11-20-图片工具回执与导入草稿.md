# 图片工具回执与导入草稿

旧 Python 的文件读取工具用原生内容块承载图片，Anthropic 历史投影直接把内容传给 `tool_result.content`。Node 在组装工具历史时把原生数组序列化为字符串，导致图片引用编解码器无法处理其中的块。现在只对工具显式提供的原生模型内容块保留数组形状。普通结构化工具结果继续走原有序列化路径。

旧 Python 的待发队列表有自增 `id`，Node 基线使用 `(user_id, queue_id)` 复合主键。导入草稿查询改为按更新时间和队列标识稳定排序，无需变更数据库结构。

验证覆盖图片回执的原生块、引用固化和恢复，以及导入队列读取契约。真实 IM 回复仍待端到端验证。
