# 2.0 统一附件保存工具

Web 上传附件和 IM 私聊附件共用 Agent 工具名 `save_attachment`。宿主按照可信会话来源选择附件保存方式，模型传入 `attach_id`。工具目录、Schema 查询和调度使用新名称。

Web 仍支持按单个 ID、批量 ID 或最近附件保存，目标可选个人文件、项目或会话绑定的工作区。IM 保留已验证 owner 私聊、机器人范围、会话水位和有效期校验，默认保存到个人文件的下载目录。新保存结果返回文件名和逻辑路径。

共享注册表只接收一个 `saveAttachment` 定义，由可信宿主装配对应保存方式。两个旧名称不作为可调用别名。内部已有写入收据标识保持稳定，避免重试时重复保存。

本次合并的是现有 Web Host 和 IM 保存入口。Desktop 本地 Agent 尚未装配附件转存端口。
