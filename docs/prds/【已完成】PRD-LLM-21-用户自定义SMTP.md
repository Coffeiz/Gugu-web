# PRD-LLM-21 用户自定义 SMTP

## 目标

允许用户在「设置 → 能力配置」中配置自己的 SMTP，用于 Agent 邮件工具发送；没有个人配置时继续使用服务器默认 SMTP。

## 交互

- 展示服务器、端口、账号、密码、发件人和 SSL/TLS 选项。
- 测试按钮发送到当前用户注册邮箱，测试未保存的表单配置；密码留空时使用已保存密码。
- 保存后邮件工具优先使用个人 SMTP。
- 关闭“启用个人 SMTP”后保留配置，但发送时回退服务器默认 SMTP。

## 安全与接口

- 用户 SMTP 单独存表，密码使用 `EncryptedString` 加密保存。
- GET 只返回非敏感元数据，不返回密码；更新时密码留空表示保持原值。
- 测试接口不持久化草稿，错误响应和日志不得包含 SMTP 密码。
- 所有接口只能操作当前用户配置。

## 验收

- 能力配置页可保存、测试和恢复默认 SMTP。
- 测试邮件默认到注册邮箱。
- Agent `send_email` 的用户 SMTP 覆盖与 Admin 默认回退均有测试。
- 前端类型检查、后端定向测试和迁移检查通过。
