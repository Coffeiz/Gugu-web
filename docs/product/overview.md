## 易读概述

**给第一次接触咕咕、想快速判断它适不适合自己的人看。**

### 它是什么

咕咕是一个让个人项目、文件、日程和想法留在同一条脉络里的工作空间。

项目不只是待办列表。一次创作、一项工作或一段生活计划，会慢慢积累材料、节点、日程和零碎念头；咕咕让这些内容自然聚集，留下属于项目自己的轨迹。

### 你可以怎么用

| 推进事情 | 留下过程 | 铺开思考 |
|----------|----------|----------|
| 用项目看板与日历安排下一步。 | 用文件库和每日记录沉淀材料。 | 用无限画布把便签、项目、文件与活动连起来。 |

需要时，直接和咕咕说话即可查询、整理或操作这些内容。它也能通过飞书、QQ、微信继续陪你处理项目，并保留稳定的画像、行为习惯与近期上下文，让每次对话不是从零开始。

> 当前是面向朋友试用与协作的**私人 Beta**。重点仍是个人工作流的打磨；团队 / 企业版放在较远期的路线图中。

## 专业细节

### 一、产品边界

咕咕是多用户网页应用，所有业务数据按 `user_id` 隔离。当前产品围绕个人项目推进与思考展开，不以团队协作或企业管理为当前目标。

| 模块 | 当前能力 | 状态 |
|------|----------|:---:|
| 项目 | 阶段看板、进度、截止日期、项目文件与日历节点 | ✅ |
| 文件库 | 项目 / 思维 / 素材 / 个人四个空间，文件夹、预览、回收站、本地与 OSS 存储 | ✅ |
| 日历 | 月 / 周视图、项目节点、自定义活动与提醒 | ✅ |
| 思维面板 | Markdown 日常记录、日期时间流、无限画布、便签与引用卡、关联连线 | ✅ |
| 咕咕协作 | 流式对话，查询和操作项目 / 文件 / 日程；全局搜索与上下文记忆 | ✅ |
| IM 接入 | 飞书、QQ、微信收发消息与文件，网页实时同步 | ✅ |

### 二、咕咕协作与记忆

对话层采用流式响应和工具调用，覆盖项目、日历、文件、定时任务、通知等常用操作；不可逆操作需要确认。支持 Anthropic、OpenAI、通义、DeepSeek、MiniMax 与 MiMo 等模型服务商。

每位用户拥有私有 `.agent/` 记忆档案：

- `profile.json`：稳定身份、偏好与长期画像；
- `pattern.json`：可复用的行为和决策习惯，带置信度与时间衰减；
- `summary.md` / `daily.md` / `memory.md`：当下重心、每日记录与长期叙事；
- `lens.json`：从反复互动中形成的解读先验。

详细设计见 [记忆系统](../agent/11-记忆系统.md)、[对话引擎总览](../agent/00-总览.md) 与 [可靠性说明](../agent/03-可靠性.md)。

### 三、技术与运行架构

| 层级 | 技术 / 约定 |

| 前端 | Vue 3、TypeScript、Vite、Pinia、Arco Design Vue、TipTap |

### 五、开发与协作

本地开发优先使用仓库根目录的 Docker Compose；也可分别启动 Python 虚拟环境和前端开发服务器。最小启动步骤以根目录 [README](../../README.md) 的“快速开始”为准。

提交前至少完成：

```bash
# 前端
cd frontend && npm run typecheck

# 后端
cd backend && PYTHONPATH=. .venv/bin/pytest
```

更具体的代码、类型、时间和安全约定见仓库根目录 [AGENTS.md](../../AGENTS.md)。
