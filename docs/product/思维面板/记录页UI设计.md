## 一句话基调

**对齐全站玻璃语言**（v2.1 定，2026-07-10）：每日一块轻玻璃底板（同定时任务面板），便签卡与定时任务卡/项目卡同款质感——记录页不再另起"纸"的视觉体系。曾试过"哑光纸片流"（借右键菜单的薄、近实底无投影），实际效果与全站语言割裂、观感单薄，一轮就废弃了。设计草案"纸条 vs 玻璃"的双语言留给 P2 画布再议（画布上的对比语义与时间流里不同）。

## 为什么横置（v2 改版记录）

第一版是纵向双列 grid + 右侧日期索引。真实数据一进来就露馅：便签多为短句，横跨半屏的宽卡片装一行字，又空又扁；右上角的小日期索引悬在大片空白旁边很尴尬。改为**一天一列、时间横向流动**后：短便签在 280px 窄列里天然紧凑；"单日单条右格空着"的问题直接消失（每天独占一列，没有格子要配对）；横置画面跟 P2 画布的"工作台"气质连续。参考形态：周视图日历（列=天、列内竖排条目）。

## 整体骨架（full-bleed，纵向四层）

`/mind` 走 full-bleed（路由 `meta.fullBleed`，DefaultLayout 据此隐藏 topbar、去掉顶部渐变遮罩、`page-content` 收窄留白且不滚动，滚动交给页面自管）。topbar 的 GlobalSearch 由胶囊条右侧的便签筛选补位。

```
[侧栏] ┌──────────────────────────────────────────────┐
       │            ( 记录 ◉ | 画布 )      [🔍 筛选]   │ ← 胶囊椭圆、水平居中
       │             ıııııIıııı                        │ ← 日期滑杆（可拖动）
       │  ┌ 10 7月周五 6┐ ┌ 9 7月 ┐ ┌ 8 7月 ┐         │
       │  │ [卡]        │ │ [卡]  │ │ [卡]   │  →横滚 │ ← 一天一列玻璃底板
       │  │ [卡]        │ │       │ │ [卡]   │       │    292px，左新右旧
       │  │ [卡] ↓列内滚 │ │       │ │ [卡]   │       │
       │  └─────────────┘ └───────┘ └────────┘       │
       │        ┌ 记点什么…              ➤ ┐           │ ← 捕捉条，居中停靠
       └──────────────────────────────────────────────┘
```

| 层 | 规格 | 玻璃？ |
|---|---|---|
| 胶囊条 | 椭圆（全圆角 999px）、**水平居中**（grid 三列布局保证真居中），筛选框靠右同排 | 可以（背后静态） |
| 日期滑杆 | 可拖动 filmstrip：playhead 固定正中，刻度带整体 `translate3d` 平移让当前日的高刻度停中线；一天一根 3px 刻度（`ıııııIıııı`），当前根加高加粗成主色，hover 微升浮出日期小签（当前常显）。鼠标拖动 1:1 跟手、松手 spring 吸附最近刻度、点某根直接吸过去 | 否——裸刻度 |
| 便签流 | 横向滚动，**每日一块轻玻璃底板**（`--glass-bg` 0.25、hover 不提亮）292px 列，**左新右旧**（今天最左）；无便签的日期**不出列**（时间轴压缩）；列头大日期数字 26px（今天主色）+ 小字月份/星期竖排 | 底板玻璃（背后静态安全）；卡片见下 |
| 捕捉条 | 视口底部停靠、**水平居中**（与胶囊呼应，max 680px）；收起 44px 单行，聚焦展开 | 玻璃面板，内部交互克制 |

**玻璃红线适用**（design.md「弹窗动画规范」+ devlog 07-01/07-06）：捕捉条浮在滚动内容之上，内部交互元素 hover 一律走 opacity 叠层，不动 background/box-shadow（白带）；任何玻璃元素的祖先链不挂 opacity/filter/mask 动画（隔离组）。

## 滚动模型（横竖两轴分工）

- **横轴 = 翻历史**：纵滚轮在列外/无溢出列上时转为横滚（`wheel` 事件 `scrollLeft += deltaY`）；触控板横扫、Shift+滚轮走浏览器原生；日期条点击直达。横向滚动条隐藏（导航靠滚轮/日期条，露在捕捉条底下很脏）。
- **竖轴 = 翻当天**：列内溢出时列内自己竖滚（细滚动条）；滚轮悬在有溢出的列上优先列内竖滚。
- **滑杆语义（v2.2 定）**：聚焦哪天、那天的列停在**屏幕正中**（轮播/剪辑时间轴语义）——「当前」=中心离容器中心最近的列，`.timeline-cols` 两端留半屏 padding 让首末列也能居中；首载今天直接定正中（不播动画），提交后今天列居中+高亮，刻度杆点击/联动同此。判定改用 **rAF 节流的 scroll 手算**（几十列一次遍历微不足道）：此前"用 IntersectionObserver 别手算"的规定只适用于"进出边界"型判定（左带模式），"最近者易主"需随每个滚动像素连续变化，是 IO 的能力边界。日期滑杆是**双向控制器**：列滚动 → active 变 → 滑杆刻度带平移回中（非拖动态才动，避免和手指打架）；拖滑杆 → 松手吸附 → emit jump → 列滚到该日居中。滑杆用实测几何（读 `offsetLeft`）+ `translate3d` 平移而非 `scrollIntoView`（浏览器 easing 不可控，拿不到 spring）。

## 便签卡片（主角，定时任务卡同款）

- **质感 = task-card / 项目卡同款**（v2.1 定）：白 56% 底 + `1px rgba(255,255,255,0.72)` 白描边 + `--radius-md` 圆角 + 轻投影，`::after` 顶部高光层，hover 加深阴影 + 高光提亮。卡自身**不用 backdrop-filter**（底板已经是玻璃）；卡内 hover/让位动画发生在底板内容层、不碰底板 backdrop，两条玻璃红线都不踩，TransitionGroup move 可放心用 transform。
- **卡内结构**：正文 13px/1.6；长内容 line-clamp 6 行 + 「展开」（阅读态展开，不进编辑）；**时间戳常驻**左上（当天只显 HH:MM，往日/补录显完整日期）；待办渲染成可勾 checkbox **卡上点击即完成**（直接 PATCH 走乐观锁，不进编辑）；对象引用小 chip；**咕咕代记微标**加工档才标（`record_note` 的 origin 字段，直录不标）。
- **可选颜色**：整卡低饱和 tint（紫灰/粉灰/青灰/暖黄），不做左侧色条。
- **编辑 = 列内就地展开**（v2 改：不再跨列）：窄列里卡片原地变编辑器（Trello 卡片式），工具栏藏掉 `@` 提示文字（放不下，捕捉条那份还在）；同列其余卡由 TransitionGroup move 让位。

## 捕捉条（底部停靠、居中）

- 收起态：单行 44px「记点什么…」+「随手记」角标；**收起不丢草稿**（单行里露草稿开头提醒"还有没记完的"）。
- 聚焦展开：编辑器 + 工具栏（正文/单级标题/待办/列表 + `@` 引用）从条内长出来，不弹浮层；补录日期选择器同排。
- 编辑器行为遵循设计草案：无 Markdown 输入规则、格式只走工具栏、`@` 引用（行首/空白前触发、连续无结果自动关）、`/` 预留咕咕。

## 提交行为

- **常规提交**：若已横滚进历史 → 先平滑滚回最左（今天列）→ 新卡插列顶 + 紫灰 12% 高亮 ~1.8s 淡出。
- **补录**（`captured_at` 是过去）：**不滚动**，toast「已记到 7 月 3 日」。不做这条反馈就是 bug——补录落进右边很远的列，眼前没有任何动静，用户会以为没保存。

## 空态
