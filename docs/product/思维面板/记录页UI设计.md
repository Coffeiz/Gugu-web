## 一句话基调

**这一页比全站其他页面更"纸"**——胶囊条和捕捉条留住玻璃语言跟全站呼应，中间整个内容区是哑光的纸片流，玻璃只出现在边缘 chrome 上。承接设计草案"纸条表示人的思考、玻璃表示系统对象"的双语言：P2 画布进来时（纸条贴纸 + 玻璃系统对象）视觉语言是连续的。

## 整体骨架（full-bleed，四个区）

`/mind` 走 full-bleed（路由 `meta.fullBleed`，DefaultLayout 据此隐藏 topbar、`page-content` 顶部留白降到 ~20px）。注意两个连带：`.layout-main::after` 的顶部渐变遮罩是为"内容溶进 topbar"设计的，没了 topbar 要重新看；topbar 里的 GlobalSearch 由胶囊条的便签筛选补位（全局搜索在别的页面仍在）。

```
[侧栏] ┌──────────────────────────────────────────────┐
       │  [ 记录 | 画布 ]              [ 🔍 筛选便签 ]  │ ← 胶囊条 ~44px
       │                                              │
       │   7月10日 · 周四                    │ 今天 ·3 │
       │   ┌────────┐ ┌────────┐            │ 7月9日·1│ ← 日期索引 ~120px
       │   │ 便签   │ │ 便签   │            │ 7月8日·5│
       │   └────────┘ └────────┘            │ 7月5日·2│
       │   7月9日 · 周三                     │         │
       │   ┌────────┐                        │         │
       │   …                                 │         │
       │                                              │
       │      ┌ 记点什么…                    ➤ ┐      │ ← 捕捉条，视口停靠
       └──────────────────────────────────────────────┘
```

| 区 | 规格 | 玻璃？ |
|---|---|---|
| 胶囊条 | ~44px 高；左「记录\|画布」分段切换（沿用 SegBar 语言），右便签筛选框 | 可以（背后是静态页面背景，安全） |
| 便签流 | 双列 grid、列间距 12px、整体 max-width ~980px 靠左；窄屏塌回单列 | 否——卡片是纸（见下） |
| 日期索引 | ~120px 裸文字条列表，无面板底 | 否——越像"页边刻度"越好 |
| 捕捉条 | 视口底部停靠，宽度与便签流对齐；收起 44px 单行，聚焦展开 ~120px | 玻璃面板，**内部交互元素克制**（hover 只做 opacity 叠层） |

**玻璃红线适用**（见 design.md「弹窗动画规范」+ devlog 07-01/07-06）：浮在滚动内容之上的捕捉条若用 backdrop-filter，内部交互元素的 hover 一律走 `::before/::after` + opacity 叠层，不动 background/box-shadow（白带）；任何玻璃元素的祖先链不挂 opacity/filter/mask 动画（隔离组）。

## 便签流

- **排序与分组**：`captured_at` 新→旧（上新下旧）；按日期分组，组标题一行「7月10日 · 周四」13px/600 + 当日计数；**组内分列、不跨天**，grid 行优先填充天然保证左→右上→下＝新→旧。
- **单日单条**：右边空格**就让它空着**（2026-07-10 定）——不做单列回退特判，规则稳定比局部满铺重要，混合列数会让新卡落点不可预测。
- **滚动加载**：API 仍按 DESC 分页，往下滚 offset 递增加载更旧的。

## 便签卡片（主角，纸不是玻璃）

- **底色近实底**：`rgba(255,255,255,0.82)` 左右，**不用 backdrop-filter**——纸的质感本该实，顺带绕开白带/隔离组两个玻璃坑，重排/展开动画可放心用 transform + FLIP。
- **借薄不借悬浮**：radius 10px、`1px solid rgba(0,0,0,0.06)` 描边、padding 11px 13px、**无投影**，老实躺在页面上（右键菜单的"薄"，去掉它的"浮"）。
- **hover**：只在 `::after` 上做 4~6% 白的 opacity 淡入。
- **卡内结构**：
  - 正文 13px/1.6；长内容 line-clamp 6 行 + 「展开」（阅读态展开，不进编辑）；
  - **时间戳常驻**右上角 11px `--text-secondary`（`14:32`；补录的显示完整日期）；
  - 待办块渲染成可勾 checkbox，**卡片上点击即完成**（直接 PATCH，不进编辑），已完成划线；
  - 对象引用渲染成小 chip（类型图标 + 名称），点击跳对应页面；
  - **咕咕代记微标**（2026-07-10 定）：**加工档标、直录档不标**——咕咕总结/提炼产出的便签右上角给极小的「咕咕整理」微标（11px 灰）；直录的内容本来就是用户的话，标了反而噪。回顾时"我的原话"和"AI 的转述"可信度不同，尤其隔了几个月回看。数据上是 `record_note` 写入时带 origin 字段。
- **可选颜色**：整卡 ~8% 低饱和 tint（紫灰 `#7b7fb2` / 粉灰 `#c4afc8` / 青灰 `#7ab8c8` / 暖黄 四选一），**不做左侧色条**——色条是"管理系统"的语言，整卡淡染才是"便签纸"的语言。

## 日期索引（右栏）

- 每条一行「7月9日 · 1」（GPT 历史栏的密度）；当前视区对应条：3px 紫灰左竖线 + 文字 `--text-primary`，其余 `--text-secondary`。
- 点击平滑滚动到对应日期组。
- 联动用 **IntersectionObserver** 盯日期组标题驱动高亮，不用 scroll 事件手算。
- 窄屏隐藏。

## 捕捉条（底部停靠）

- 收起态：单行 44px「记点什么…」+ 发送键。
- 聚焦展开：~120px，工具栏（正文/标题/待办/列表 + `@` 引用）**从条内长出来，不弹浮层**。
- 编辑器行为遵循设计草案：无 Markdown 输入规则、格式只走工具栏、`@` 引用 `/` 预留咕咕。

## 交互与动画

- **提交**：若用户已翻进历史 → 先平滑滚回顶部 → 新卡 FLIP 插入 + 紫灰 12% 高亮 tint ~1.5s 淡出。
- **补录**（`captured_at` 是过去）：**不滚动**，toast「已记到 7 月 3 日」（可点跳转）。不做这条反馈就是 bug——用户会以为没保存。
- **就地展开编辑**：点卡片 → 该卡 FLIP 跨满两列、长高成编辑器（工具栏在卡内顶部出现），同组其余卡让位重排；ESC/点外部收起。全程 transform 动画（卡片是纸，不受玻璃 transform 禁令约束）。
- **切换 记录⇄画布**：P2 时定，先简单 crossfade 占位。

## 空态
