## 验收原则

- 源路由表记录每个 method/path 的当前状态和必要证据；详细实现过程、历史测试快照及已被后续结果替代的记录放在 devlog。
- 只有 Node 行为、真实依赖与调用方切换均验收后，才算对应迁移完成；显式不可用响应、路由挂载或 mock-only 回归不代表完成。
- 全部 Web 必需 HTTP、SSE、静态资源及后台调用方具备等价实现和实机证据后，才切换默认 Node Web 流量。
