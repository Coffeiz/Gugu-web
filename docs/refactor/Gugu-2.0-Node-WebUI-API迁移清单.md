## 当前状态

2.0 由 Node Web Host 提供 API、SSE、WebSocket 和后台任务。Vite 主站（含终端）与独立 Admin 统一使用 `VITE_API_PROXY_TARGET` 指定的 Node Host 或默认 9595；终端 WebSocket 保留浏览器 Host 以校验 Cookie 请求的 Origin。下文双运行时和旧代理描述仅反映历史快照。

本轮 devserver 的终端 WebSocket、RAG Worker、会话工具和索引迁移回归共 25 通过、0 失败、0 跳过，Host 生产类型检查通过。Vite 终端回归使用合成账号和 PTY，覆盖同源 Cookie 握手以及跨源请求在终端启动前被拒绝。另以合成 Node HTTP 上游验证主站终端和独立 Admin 代理。RAG 使用临时 SQLite、隔离 PostgreSQL 和模拟 Provider，覆盖 owner 隔离、全来源索引补建及并发入队。生产部署、真实 MXC 与外部 Provider 未验收。

## 验收原则

- 源路由表记录每个 method/path 的当前状态和必要证据；详细实现过程、历史测试快照及已被后续结果替代的记录放在 devlog。
- 只有 Node 行为、真实依赖与调用方切换均验收后，才算对应迁移完成；显式不可用响应、路由挂载或 mock-only 回归不代表完成。
- 全部 Web 必需 HTTP、SSE、静态资源及后台调用方具备等价实现和实机证据后，才切换默认 Node Web 流量。
