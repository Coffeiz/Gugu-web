# 图标系统统一重构方案

## 1. 文档状态

| 项目 | 内容 |
| --- | --- |
| 状态 | Phase 0-2、Phase 4 已完成；Phase 3 尚未开始 |
| 调查范围 | `frontend/src` 全部 Vue/TS 页面与组件 |
| 目标 | 将通用界面图标统一迁移到 Remix Icon |
| 当前实现 | Phosphor Icons、Arco Icon、内联 SVG 混用 |
| 非目标 | 不替换 Logo、连接线、画布点阵、文件缩略图和纯装饰 SVG |

## 2. 背景与结论

当前前端图标来源较多，导致图标命名、描边粗细、填充风格、尺寸和主题颜色难以统一。后续设计令牌和暗色模式继续推进时，图标仍然需要在多个组件内单独调整。

本次重构的目标不是简单批量替换 SVG，而是建立一层统一的图标语义接口：业务组件只声明语义名称、尺寸和视觉风格，具体使用哪个 Remix Icon 由统一映射表决定。

迁移完成后，业务代码不应继续直接依赖 `@phosphor-icons/vue`、Arco 全局图标组件或重复的通用内联 SVG。

## 3. 现状清点

### 3.1 Phosphor Icons

- 依赖：`@phosphor-icons/vue`
- 使用文件：89 个
- 不同图标：121 个
- 统计到的导入引用：约 334 处
- 覆盖范围：主导航、Admin、项目、日历、文件库、聊天、画布、查看器、设计令牌页

主要图标族包括：

```text

文件：File、Folder、Archive、FileText、Image、FilmStrip、MusicNote、Code
聊天：ArrowRight、Paperclip、Microphone、Play、Pause、Stop、Speaker*
画布：Graph、NotePencil、SquaresFour、Caret*、Trash
Admin：Gear、Robot、Brain、Terminal、Chart*、Users、Pulse

```

### 3.2 内联 SVG

- 使用文件：54 个
- 统计到的 SVG 出现：约 168 处
- 主要用途：
  - 日期选择器的日历、箭头和星期标题
  - 登录、注册、找回密码页面的装饰图形
  - 画布连接点、连接线和节点几何图形
  - 文件列表、文件上传和项目卡片中的业务状态图形
  - Markdown/编辑器复制状态图标
  - Admin 局部页面的状态和装饰图形

内联 SVG 不能全部机械迁移。凡是承担几何、连接、遮罩、路径动画或品牌识别职责的 SVG，应继续由业务组件保留。

### 3.3 Arco Icon

`frontend/src/main.ts` 目前全局注册了 `ArcoVueIcon`。本次清理应检查实际模板使用情况；如果没有业务页面继续使用 Arco 图标，则移除全局注册和相关依赖。

### 3.4 当前不存在的内容

- 已安装 `@remixicon/vue@4.9.0`，许可证为 `Remix Icon License 1.0`；
- 已新增统一的 `Icon` 组件、语义映射表和类型定义；
- 已新增四档尺寸、颜色语义令牌，并接入全局 adoption 样式；
- 已完成 Phase 2 范围内共享组件、文件库、项目、日历、聊天和设置页面的通用操作图标迁移；Admin、Mind 画布、DesignSystemPage 和文件类型图标仍按后续阶段/例外处理。

## 4. 目标架构

```text
frontend/src/
├── components/common/Icon.vue              # 唯一业务入口
├── components/common/iconRegistry.ts       # 语义名到 Remix 图标的映射
├── components/common/iconTypes.ts          # 类型、尺寸、风格定义
├── assets/styles/tokens/components/icons.css
└── assets/styles/adoption/icons.css
```

推荐调用方式：

```vue
<Icon name="action.delete" size="sm" title="删除" />
<Icon name="navigation.projects" size="md" />
<Icon name="file.pdf" size="lg" tone="muted" />
```

禁止业务组件直接写：

```ts
import { PhTrash } from '@phosphor-icons/vue'
```

`Icon.vue` 负责：

- 读取语义名称并解析 Remix 图标；
- 统一 `size`、`tone` 和 `decorative`；Remix Icon 的填充/线性差异由语义映射决定；
- 对缺失映射直接抛错，不静默替换成错误图标；
- 通过 `aria-hidden`、`aria-label` 和 `title` 保持可访问性；
- 保留必要的 `class`、`style` 和事件透传能力；
- 不接管按钮的 hover、disabled、active 或 loading 状态。

## 5. 图标语义命名

映射表按业务语义命名，不按 Remix 图标原始名称命名。

| 语义空间 | 示例 | 用途 |
| --- | --- | --- |
| `navigation.*` | `navigation.projects` | 侧栏和页面导航 |
| `action.*` | `action.delete`、`action.edit` | 删除、编辑、复制、下载 |
| `file.*` | `file.folder`、`file.pdf` | 文件类型与文件夹 |
| `status.*` | `status.success`、`status.warning` | 成功、警告、错误 |
| `media.*` | `media.play`、`media.pause` | 音视频操作 |
| `editor.*` | `editor.bold`、`editor.link` | 编辑器工具栏 |
| `canvas.*` | `canvas.node`、`canvas.connection` | 画布专用语义 |
| `admin.*` | `admin.settings`、`admin.audit` | Admin 页面专用语义 |
| `brand.*` | `brand.gugu` | 品牌图形，仅在确有 Remix 对应物时使用 |

一个语义名只能对应一个默认图标。不同主题通过颜色令牌变化，不通过替换图标名称变化。

## 6. 令牌设计

新增图标令牌应尽量控制在四档，与现有字体和圆角限制保持一致：

```css
--icon-size-xs: 12px;
--icon-size-sm: 14px;
--icon-size-md: 16px;
--icon-size-lg: 20px;

--icon-color-default: var(--content-secondary);
--icon-color-muted: var(--content-tertiary);
--icon-color-active: var(--action-primary);
--icon-color-danger: var(--status-danger);
```

组件内部优先使用 `currentColor`。不要在映射表中写死主题颜色，也不要为单个页面新增独立尺寸。结构性 SVG 的线宽仍由其自身几何样式管理，不纳入 Remix 入口的通用参数。

## 7. 迁移边界

### 7.1 优先迁移

- 主应用侧栏与顶部导航；
- 文件库工具栏、文件操作菜单、上传按钮；
- 项目卡、项目文件和项目阶段操作；
- 日历工具栏和日期选择器中的通用操作图标；
- GuguChat 的发送、停止、复制、展开和收起按钮；
- Admin 的刷新、设置、日志、用户和服务图标；
- Design 页面中用于展示组件状态的图标。

### 7.2 暂时保留

- Gugu Logo 和品牌头像；
- 画布连接点、连线箭头、点阵背景和节点几何图形；
- 日期网格中的结构性 SVG；
- 文件类型大图标，除非 Remix 图标能保持现有识别度；
- Markdown、代码编辑器和富文本中的结构性 SVG；
- 登录/注册页的插画和装饰图形。

### 7.3 明确清理

- 无实际使用的 Arco 图标全局注册；
- 业务组件中重复定义的同义通用 SVG；
- 同一语义使用多个不同图标的旧映射；
- 直接从 Phosphor 导入但只用于简单操作按钮的组件代码。

## 10. 风险与回滚

| 风险 | 处理方式 |
| --- | --- |
| Remix 图标视觉重量与 Phosphor 不一致 | 先统一线宽和尺寸，必要时保留局部例外 |
| 某些语义没有合适的 Remix 图标 | 通过映射表登记例外，不使用相近但语义错误的图标 |
| 画布 SVG 被误替换影响交互 | 画布结构性 SVG 不纳入批量迁移 |
| Admin 页面图标对比度下降 | 亮/暗主题分别做截图和对比度检查 |
| 迁移中出现大量 diff 难以定位 | 按共享组件、业务模块、Admin 分阶段提交 |
| 第三方依赖体积变化 | 检查构建产物，优先使用按需导入，不使用全量 CSS 图标字体 |

回滚以阶段为单位进行。每个阶段结束都保留通过 typecheck、测试和构建的提交，不采用一次性大范围替换。

## 11. 最终目标

最终业务组件只需要：

```vue
<Icon name="action.delete" size="sm" title="删除" />
```

而不需要知道底层使用的是哪一个 Remix 图标组件。图标选择、尺寸、线宽、主题颜色、可访问性和迁移例外都由统一图标层管理。
