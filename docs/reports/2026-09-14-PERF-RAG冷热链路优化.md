## 2. 修复清单（按层）

### 2.1 worker 计算层

- **install 标记-清扫 + 词项倒排预聚合**（两级 O(n²)）：逐条 remove/add 的全量数组拷贝与 posting 线性搬移 → 账目批处理 + 预聚合重建。全量重灌 68s → 0.78s。
- **词法指纹跳过**：来源级重建整表推时间戳，水位增量退化成全表重灌（每轮 install 6.8s）。install 入口对每条 upsert 做词法指纹预检（对齐 delta.py 契约：版本/时间戳不参与），内容未变即跳过分词。整表重写 5,000 条实测 48ms。指纹（内容 digest）与水位（时间戳）是互补的两层。
- **snapshotCovers 塌缩**（dedup 热点）：前缀逐字符回退 + 每文档重跑快照归一化 ≈ GB 级字符串扫描 → 利用前缀包含的单调性塌缩为单次 `includes`。见 §3 A/B。

### 2.2 恢复与调度层

- 构建预算 30s → 120s（兜底）；诊断模式七态真实落盘；mismatch 回退显式 `source_replace`；重放事件标注 `event_replayed`。
- 延迟落盘：sync 响应先行，64MB 快照写入挪到 1.5s 空闲窗口（追边合并 + 防重入）。崩溃窗口由「旧快照 + 旧水位重放 + 指纹吸收」兜底。查询路径每轮省 ~650ms。
- 合并正确性：bus `_rag_pending` 按 source_id 保留集合；outbox 增 `pending_source_ids`（迁移 20260914000001），重放逐 ID 展开、成功逐 ID 移除，集合非空保持 queued。

### 2.3 正确性修复（性能排查的副产品）

- `apply_document_patch` 只收 delta.upserts → 未变化 chunk 被误墓碑，部分编辑静默丢内容（P1，回归 `test_partial_edit_keeps_unchanged_chunks`）；
- `record_index_update` 的 `_log`/`json` 未定义，写路径诊断自上线起静默空转（P1）；
- `update_document` 死的全量 `load_index_documents`（O(来源规模)），删除后单文档 patch p50 79ms → 7.5ms。

## 3. A/B 测试：dedup 热点（真实数据，双 bundle 交替）

旧 bundle（git 历史版本）与新 bundle 各起独立 worker，对同一 owner 的真实存储执行 `prepare_memory`，3 轮交替：

| 指标 | 旧（逐字符前缀回退） | 新（单调性塌缩为单次 includes） |
|---|---|---|
| snapshot_dedup_filter | 323–347ms | **13–20ms（~25×）** |
| prepare_memory 整体 | 466–483ms | **154–195ms（2.69×）** |
| 文档读取 / 瞬态安装 | 17–36 / 103–130ms | 不变（非热点） |

语义等价性：前缀包含单调 ⇒ 回退循环 ≡ `includes(minimum 前缀)`；另以 2,800 例随机样本（精确覆盖 / 80% / 76% / 68% 边界 / 短文本兜底）对拍，零偏差。worker 协议套件 62/62。

C 对照基准（同机同文件）：C 解析 193ms vs Node `JSON.parse` 262ms——证明换语言收益有限，**瓶颈在冷堆分配与 UTF-16 解码，不在解析算法**。

## 5. 决策记录

1. **预热方案否决**：实测每个热 owner worker 常驻 358MB RSS，「前 20 活跃 owner」≈7GB 不收敛；K=3 边际收益不足。改为自动召回窗口 5s → 10s（用户拍板）。
2. **C/native addon 否决**：C 解析仅比 V8 快 3 倍，4.1s 中解析只占 0.26s，引入编译工具链不值。
3. **水位复用救不了时间戳重写**：来源级重建推高整来源 `indexed_at`，水位 delta 退化为全表；指纹跳过才是对症药。
4. **mmap 收益有限**：`mmap` 的 0ms 读是把 IO 藏进扫描缺页；Node 路径省不掉 UTF-8→UTF-16 解码（~300ms）。二进制快照格式留待快照涨到几百 MB 时一并做。

## 6. 观测能力沉淀

- worker install 分段：`install_tokenize_ms` / `install_structure_ms` / `install_skipped_documents`；
- 宿主分段：`host_queue_ms` / `host_upstream_ms`（补齐宿主内排队盲区）；
- 超时进度留存：自动召回超时即打 `source_progress` / `pending_sources` 快照（上下文销毁前抢救）；
- 诊断七态：`document_patch / source_replace / revision_mismatch / worker_unavailable / projection_failed / event_replayed / no_change` 真实落日志并有断言。

## 7. 遗留与观察项

1. 热态 unified 检索的 180–590ms 波动（含宿主排队），量级可接受，观察；
