> 测试日期：2026-11-15
> 环境：devserver，测试身份与独立临时评测目录
> 模型：后端已有 deepseek-flash 预设

## 1. 结论

完成官方 LoCoMo 全部 10 段对话的 1,540 道非对抗题，按题平均 F1 为 **49.49%**，按对话等权平均为 **49.38%**。共 272 个实际会话，模型生成 2,823 条模拟事实。319 题回答 unknown，占 20.71%。

这是“模拟事实提取 → 生产 Cython BM25 Top 12 → dsflash 批量作答”的离线结果，不是完整线上 Agent 或自动反思链路成绩。F1 是词级重合指标，不是准确率。

## 4. 设置与完整性

- 数据使用同一份官方 locomo10.json；SHA-256 与[单段报告](./2026-11-15-TEST-LoCoMo记忆召回隔离评测.md)一致。
- 排除 category 5 的 446 道对抗题；10 段非对抗题共 1540 道全部取得非空答案。检查每段身份、问题编号集合、参考答案和分类，未发现漏题或多题。
- 只向记忆提取模型提供对话、日期和数据集图片描述，不提供 QA 标准答案或官方 observation/summary。各段记忆独立保存、独立索引。
- 前七段复用此前生成的 dsflash 模拟记忆；后三段新生成；首段复用先前 BM25 答案，其余从独立 BM25 结果目录续跑。未混入 hybrid 答案。
- 每题 Cython BM25 取 12 条事实；每个答题请求包含最多 8 题及各自检索结果，提示要求独立英文简短作答，缺少依据时回答 unknown。所有模型调用串行。
- 批量请求中模型可以看到其他题目和记忆，因此不是严格逐题上下文隔离。
- 评分复用官方 evaluation.py 的 normalize_answer、f1_score、f1；多跳按官方多答案 F1，其余按词级 F1。

## 5. 过程与性能限制

原先尝试的全量 hybrid 在第七段向量构建阶段经用户要求停止，转为 BM25。期间 devserver 内存与 Swap 饱和，评测暂停；资源恢复后继续。

本次恢复后，各段进程耗时合计约 406 秒，其中包括跳过首段、复用已生成记忆、继续未完成答案及最后三段的新记忆提取。它不是从零完成全量评测的耗时。受中断、资源争用和已有产物复用影响，不汇总一个容易误解的端到端总耗时。未测并发，不报告费用或缓存率。

## 6. 对照解读

首段 BM25 F1 为 46.70%，全量为 49.49%。各段为 44.27%–54.52%，说明首段不能代表整个集合。

此前 48.54% 是首段 hybrid 的结果，不能与全量 BM25 49.49% 直接比较来判断哪种检索更好。此前 63.82% 语义正确率也只适用于首段 hybrid，尚未对本次 1540 条输出做同口径语义审阅。

开放领域 17.95% 较低，仍同时受到事实抽取、词法候选、保守答题提示和 F1 口径影响。多跳 30.74% 需要进一步检查列表漏项与证据聚合，暂未完成逐题归因。

## 7. 测试脚本与产物

- 使用[已归档的 BM25 脚本](../../backend/scripts/benchmarks/locomo/bench_locomo_sim.py)。实际完整调度器仅按顺序为其提供各段单元素数据文件，不修改算法或提示。
- [全量脱敏统计](./results/locomo-20261115/bm25-full-metrics.json)。
- 每段原始状态保存在 devserver 的 `/tmp/gugu-locomo-bm25-full-20261115/sample-XX/state.json`；尚未清理，临时目录不保证长期保存。
- 读取后台配置及测试账号记录、调用真实 Provider；仅写入隔离评测文件，不写真实用户记忆、不改运行配置。

复现时把官方数据逐段拆成单元素 JSON 数组，分别使用独立输出目录，串行执行：

```bash
cd <devserver仓库根目录>/backend
PYTHONPATH=. .venv/bin/python scripts/benchmarks/locomo/bench_locomo_sim.py \
  --allow-real-llm --user-id <测试账号UUID> \
  --dataset <评测目录>/sample-XX/dataset.json \
  --output <评测目录>/sample-XX
```

该脚本仍按名称选择 deepseek 预设，非通用评测框架；不要把不同模型或数据写进同一已有结果目录。若需要严格复现，从空目录重建全部记忆与答案，并固定模型与上游数据版本。
