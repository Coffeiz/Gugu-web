# 全局搜索的 Core 边界

Web Host 将认证用户交给 Core 搜索用例，并装配 PostgreSQL 来源。查询解析、结果分组和缺失来源检查在 Core；HTTP 认证与错误映射仍在 Host。

SQLite 来源工厂目前只提供项目、日程和联系人。仓库还存在独立的 SQLite 对话搜索实现，但未在该工厂或 Desktop Runtime 中装配；Desktop 也尚无搜索调用入口。SQLite 已存在便签、画布和定时任务等表并不代表对应搜索来源已经接通，文件等来源还依赖 2.0 授权 FS 方案。未指定类型且缺少来源时，Core 会明确返回能力缺失错误，不把缺口当作零结果。

完成桌面搜索需按实际平台装配可用来源，核对各来源的 owner、软删除、排序和数据投影，并在真实 SQLite 与 Desktop 调用链上验收；未实现的来源仍需明确报缺失。本说明不将独立来源测试等同于产品入口已接通。
