# 使用咕咕 CLI

此 Skill 随 `@gugu/cli` 维护。CLI 和服务端接入目前尚未实现；不要假定 `gugu` 命令或下列业务能力已经可用。实现完成后，本文件应随实际接口同步更新。

1. 先读取 CLI 的 `--help` 和所需子命令的帮助，确认已安装的版本、参数和目标实例；不要猜测参数或 ID。
2. 面向程序使用时读取 `--json` 输出和退出码，以实际版本的帮助和 README 为准。不要解析 Agent 工具的文本回执。
3. 使用用户已授权的实例和账号。写入遵循用户意图与目标 Host 的权限门；不要绕过认证或把凭据放入命令参数、聊天或日志。
4. 写操作结果未知时先查询目标状态，避免盲目重试造成重复操作。

首期计划覆盖项目、日历、笔记、画布和定时任务。具体命令、认证方式及返回结构实现后见本包 [README](../../README.md)。
