# Agent 内置资源

- `prompts/` 保存默认提示词。Core 按文件名读取，`prompts/im/` 包含 IM 群聊与成员记忆相关模板。
- `skills/` 保存内置技能正文。Core 构建时将其打包为内置技能模块，Agent 按技能加载流程读取。

桌面端构建从 `prompts/` 复制模板到 Agent 运行模块旁的 `agent-prompts/`，沿用 sidecar 的运行目录。Web Host 通过 Core 读取默认模板，优先读取文件存储根目录下的 `.agent-prompts/` 覆盖文件。旧部署的 `assets/agent-prompts/` 仍可用于导入自定义覆盖，已有覆盖优先。

维护默认行为时在此处修改源文件。用户安装的技能和管理员保存的提示词由运行时数据目录管理。

`retrieval.md` 已退役。检索规则由默认提示词、人格提示词和对应技能维护。若部署曾手工放置同名覆盖，升级前可将仍需使用的规则合并到现有模板。旧文件保留在部署的数据目录中，运行时已停止读取。
