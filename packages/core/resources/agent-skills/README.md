# Node 内置 Skill 制品资源

`manifest.json` 是显式打包白名单。十份 Markdown 从当前 Python 基准逐字节复制；Python 的十三份原文继续保留为行为基准，不由 Node 构建读取或修改。排除项及原因单独列在 manifest 中。

构建脚本读取本目录并生成独立的 `bundled.js` 与声明文件。生成模块只提供可按需读取的文档，不访问运行时文件系统或 Python 目录，不自动注册技能、启用工具或授予任何 capability。可信 Host 仍需装配 SkillRegistry、权限服务及真实工具后端。

资源可打包不代表正文提及的搜索、邮件、画布、媒体、平台绑定等后端已经迁移或验收。S3 文件操作、S10 定时任务、S11 Shell 工作区正文涉及尚待重设计或未就绪的依赖，暂不进入制品；不得据此恢复旧存储或 Docker 沙盒边界。

更新正文时，先核对 Python 行为与 2.0 架构决策，再显式更新本目录和白名单。目录中新添文件不会自动启用或进入制品。
