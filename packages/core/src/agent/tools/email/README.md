# 邮件工具

[共享工具约定](../README.md)定义参数校验、运行授权、确认与收据。[邮箱包说明](../../../../../email/README.md)介绍宿主接入和 IMAP/SMTP。

## 桌面端

已连接的账户通过系统提示词中的 `[可用邮箱]` 提供账号引用、地址、可选名称和发件能力。凭据不会注入。桌面会话和经过所有者绑定校验的 IM 私聊可以使用邮件能力。群聊和普通群成员不读取账户信息或邮件。

| 工具 | 参数与行为 |
| --- | --- |
| `list_mail` | `account` 是提示词中的账号引用，或 `all` 代表全部账户的收件箱。省略 `query` 查看最近邮件，提供时只按邮件标题搜索。`limit` 默认 10，范围 1–50。返回账户、主题、发件人、日期和已读状态，不读取正文或附件，也不改已读状态。 |
| `send_email` | 提供 `subject`、`body` 和收件人 `to`（也可使用 `client_id`）。仅有一个可发件账户时可省略 `account`，多个账户时须明确选择。省略收件人时使用所选账户自己的地址。本机附件只接受当前消息的 `file_refs`。 |
| `send_email(draft: true)` | 保存到所选账户的 IMAP 草稿箱，不访问 SMTP。用户可以在邮箱页面编辑后发送。草稿写入也有持久尝试收据，结果不明时不自动重复保存。 |

实际发送强制等待「确认发送 / 取消」。确认中显示发件账户、收件人、主题、正文、格式及附件摘要，QQ、飞书和 Telegram 私聊复用现有交互选项。微信私聊当前没有发送确认入口。无法在 IM 完整显示的长邮件或复杂格式，请在桌面发起确认，或先保存草稿。确认绑定账户配置版本、目标、渲染结果与附件内容。SMTP 结果不确定时先核对收件箱或已发送邮件。

## 邮件样式

与旧 Python 邮件能力一致，`format` 有三个选项：

- `plain`：纯文本。
- `template`：咕咕模板 HTML 与纯文本，默认格式。模板类型可用 `notification`（默认）、`reminder`、`report`、`security`、`test`，可设置标题、摘要、分段、操作链接与配色。
- `html`：清理后的自定义 HTML 与纯文本。必须同时提供 `html` 和 `body`。

## Web 与定时任务

Web 当前仍使用原有 SMTP 发送适配，由共享工具执行交互确认。Web 的已接入邮箱尚未绑定到 Agent 工具。`list_mail`、账号选择和草稿当前由桌面提供。Web 定时邮件仍由定时任务的独立预授权路径处理，已连接的账户不会自动扩大任务权限。
