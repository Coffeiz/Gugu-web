# 总览工具

组入口见 [index.ts](./index.ts)。[工具开发规范](../README.md) 定义共同的参数校验、能力装配、授权和错误处理。

## 返回与权限

只读聚合当前 owner 的近期项目与日历事项。数据来源及时钟由宿主装配。

## 工具契约

### `get_upcoming`

汇总近期（默认 7 天内）要截止的项目与日历事件，按日期排序。用于回答「最近要忙什么」。若结果跨至少 3 个日期且有至少 4 项安排，首轮答复默认附 Mermaid timeline；只展示返回的日期和事项，不推断持续时间。

实现与返回契约见 [createUpcomingTool](./index.ts#L12)。执行类型为 `read`。

| 参数 | 必填 | 类型与约束 |
| --- | --- | --- |
| `days` | 否 | `type='integer'`，`minimum=1`，`maximum=366` |
