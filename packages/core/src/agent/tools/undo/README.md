# 撤销工具

组入口见 [index.ts](./index.ts)。[工具开发规范](../README.md) 定义共同的参数校验、能力装配、授权和错误处理。

## 返回与权限

目标由宿主在当前会话和 Run 范围选定。恢复时只处理原调用关联的撤销操作，结果区分执行、无可撤销操作和状态冲突。

## 工具契约

### `undo_last_action`

撤销当前 Agent Run 中最近一项仍可撤销的操作；只处理本会话、本轮运行产生的操作，不接受目标 ID。

实现与返回契约见 [createUndoLastActionTool](./tools.ts#L19)。执行类型为 `write`。

无输入字段。
